# 大量用血申请单状态码

## 来源
ObjectScript 类 Parameter 定义，用于输血科大量用血申请单流程控制。

## 状态码表

| 状态码 | Parameter 名 | 中文名称 | 说明 |
|--------|-------------|---------|------|
| 10 | `Wait` | 待审 | 申请提交后待审核 |
| 15 | `Discard` | 作废 | 申请作废 |
| 20 | `DepartWait` | 医务科待审 | 医务科审核阶段 |
| 21 | `TisWait` | 输血科待审批 | 输血科审批阶段 |
| 23 | `DirectWait` | 临床主任待审 | 临床主任审核阶段 |
| 24 | `DirectReject` | 临床主任拒审 | 临床主任驳回 |
| 25 | `Auth` | 审核 | 审核通过 |
| 30 | `Unapprove` | 医务科拒审 | 医务科驳回 |
| 31 | `TisReject` | 输血科拒审批 | 输血科驳回 |
| 35 | `Receive` | 接收 | 输血科接收 |
| 37 | `UnReceive` | 取消接收 | 取消接收 |
| 40 | `Reject` | 输血科拒收 | 输血科拒收 |

## 流程示意

```
申请提交 → [10] 待审
              ├─ [15] 作废（终止）
              ├─ [20] 医务科待审
              │     ├─ [25] 审核 → [21] 输血科待审批 / [23] 临床主任待审
              │     └─ [30] 医务科拒审（驳回）
              ├─ [21] 输血科待审批
              │     ├─ [35] 接收 → [37] 取消接收
              │     └─ [31] 输血科拒审批（驳回）
              ├─ [23] 临床主任待审
              │     ├─ [25] 审核
              │     └─ [24] 临床主任拒审（驳回）
              └─ [40] 输血科拒收（驳回）
```
