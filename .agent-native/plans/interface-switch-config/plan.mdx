## 概述

为 IRIS HIS 构建**接口开关配置管理系统**，管理员可动态控制各对外接口及子节点的启用/停用。

核心业务逻辑：**节点实际状态 = 接口总开关 AND 节点自身开关**，每个接口独立一套开关体系。

## 数据存储设计

全局变量前缀 `^YZSYInterfaceSwitch`：

<Code
  id="data-global"
  language="text"
  code={`^YZSYInterfaceSwitch("InterfaceDef", interfaceCode) = "接口中文名"
^YZSYInterfaceSwitch("NodeDef", interfaceCode, nodeCode) = "节点中文名"
^YZSYInterfaceSwitch("Master", interfaceCode) = "ON" / "OFF"
^YZSYInterfaceSwitch("Node", interfaceCode, nodeCode) = "ON" / "OFF"`}
/>

新增时默认 OFF，删除接口时一并清理下属所有节点数据。

## 后端 CLS 方法

类名：`web.YZSY.YZSYInterfaceSwitchManager`，继承 `DHCDoc.Util.RegisteredObject`。

<Table

## 前端 CSP 页面

技术栈：HISUI 框架 + EasyUI + `$cm` 通信。所有接口纵向排列，一屏显示，超出滚动。

核心交互：

<Table
  id="frontend-interactions"
  columns={["操作", "后端调用", "UI响应"]}
  rows={[
    ["页面加载", "GetAllInterfaces()", "动态渲染所有接口区域"],
    ["总开关切换", "SetMasterSwitch()", "刷新节点表格状态/禁用态"],
    ["节点开关切换", "SetNodeSwitch()", "更新状态列 + 轻提示"],
    ["新增接口/节点", "AddInterface/AddNode", "弹窗输入 → 刷新列表"],
    ["删除接口/节点", "DeleteInterface/DeleteNode", "确认弹窗 → 移除"]
  ]}
/>

开关联动：总开关关闭时节点表格整区置灰、开关 disabled、状态列统一「关」。总开关打开恢复可操作，状态按 AND 计算。

HISUI 配色：body `#cee4ff`，标题 `#15428b`，面板 `#F9FBFF`。组件用 EasyUI switchbutton + datagrid formatter。

## 实施步骤

分两阶段：先 CLS 后 CSP，两个文件一次交付。

### 阶段 1：后端 CLS

1. 创建 `web.YZSY.YZSYInterfaceSwitchManager.cls`
2. 实现 8 个方法，加 `lock +^YZSYInterfaceSwitch:n` 并发保护
3. `GetSwitchStatus` 实现 AND 逻辑计算 Status
4. 编译验证

### 阶段 2：CSP 页面

1. 创建 `yzsyinterfaceswitchconfig.csp`，用 `<EXTHEALTH:HEAD>` + `<HISUI>` 模板
2. JS 动态构建接口区域 + switchbutton/datagrid
3. 总开关联动节点表格置灰
4. 新增/删除弹窗 + AJAX 即时保存
5. IE11 兼容验证
