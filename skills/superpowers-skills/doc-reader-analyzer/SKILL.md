# 通用文档阅读整理分析归纳

本 skill 提供多格式文档的全流程处理能力：读取 → 提取 → 分析 → 归纳 → 输出。适用于技术文档、合同、报告、论文、会议纪要等各类文档。

## 触发条件

- "帮我读一下这个文档"
- "总结这份报告"
- "对比这几份文件"
- "提取文档中的关键信息"
- "分析文档结构"
- "整理成表格/大纲"
- 任何涉及文档阅读、分析、归纳的需求

## 支持格式

| 格式 | 处理方式 |
|------|----------|
| .txt / .md / .json / .xml / .yaml / .csv | 直接文本读取 |
| .pdf | 文本提取 + 表格识别 |
| .docx | 段落/表格/样式解析 |
| .xlsx / .xls | 工作表遍历 + 数据提取 |
| .pptx | 幻灯片文本提取 |
| .html / .htm | 正文提取（去标签） |
| 图片 (.png/.jpg/.bmp) | OCR 文字识别 |

---

## 一、文档读取阶段

### 1.1 单文档读取

1. 确认文件路径和格式
2. 选择合适的读取工具
3. 全量读取或分页读取（超大文件）
4. 记录文档元信息：文件名、大小、页数/行数、创建时间

### 1.2 批量文档读取

1. 列出目标目录下所有匹配文件
2. 按文件名/时间/类型排序
3. 逐个读取并标注来源
4. 建立文档索引清单

---

## 二、内容提取阶段

### 2.1 结构化提取策略

根据文档类型选择提取策略：

| 文档类型 | 提取重点 |
|----------|----------|
| 技术文档 | 架构描述、API 定义、配置参数、依赖关系、版本号 |
| 合同/协议 | 签约方、金额、日期、条款、违约责任、生效条件 |
| 报告/论文 | 摘要、结论、数据表格、图表标题、参考文献 |
| 会议纪要 | 时间、参会人、决议事项、待办任务、截止日期 |
| 代码文件 | 函数签名、类结构、注释、TODO、import 依赖 |
| 通用 | 标题层级、列表项、加粗/高亮文本、数字/日期 |

### 2.2 提取方法

- **标题层级提取**：按 H1-H6 构建文档大纲
- **表格提取**：识别并保留表格结构，标注位置
- **关键实体提取**：人名、地名、日期、金额、百分比、编号
- **段落聚类**：相似内容段落合并为逻辑块

---

## 三、分析阶段

### 3.1 分析维度

| 维度 | 适用场景 | 输出形式 |
|------|----------|----------|
| 结构分析 | 了解文档组织方式 | 目录树 / 大纲 |
| 主题分析 | 提取核心观点 | 摘要 + 关键词 |
| 对比分析 | 多文档差异 | 对比表格 |
| 时序分析 | 时间线梳理 | 时间轴 |
| 关系分析 | 实体间关联 | 关系图描述 |
| 合规分析 | 合同/规范检查 | 检查清单 |
| 数据统计 | 数字型文档 | 统计图表描述 |

### 3.2 多文档对比流程

1. 分别提取各文档的结构和关键信息
2. 按相同维度对齐（主题/时间/章节）
3. 标注差异点：新增、删除、修改
4. 生成对比矩阵

---

## 四、归纳输出阶段

### 4.1 输出模板

**摘要模板：**
```
## 文档摘要

**文档**：[文件名]
**类型**：[文档类型]
**篇幅**：[页数/字数]

### 核心结论
[3-5 句话概括]

### 关键要点
- 要点 1
- 要点 2
- 要点 3

### 数据亮点
| 指标 | 数值 |
|------|------|
```

**对比模板：**
```
## 文档对比分析

| 维度 | 文档 A | 文档 B | 差异 |
|------|--------|--------|------|
| 主题 |        |        |      |
| 关键数据 |    |        |      |
| 结论   |        |        |      |

### 主要变化
1. 新增：...
2. 修改：...
3. 删除：...
```

**结构化大纲模板：**
```
## 文档大纲

1. [一级标题]
   1.1 [二级标题]
   1.2 [二级标题]
2. [一级标题]
   ...
```

### 4.2 输出原则

- **先结论后细节**：摘要在前，详细分析在后
- **表格优先**：对比、列表、参数类信息用表格
- **标注来源**：引用原文时标注段落/页码
- **不确定标注**：推断内容标注"推测"或"待确认"
- **保持客观**：区分"原文所述"与"分析推断"

---

## 五、质量检查清单

输出前逐项确认：

- [ ] 文档已完整读取（非截断）
- [ ] 格式解析正确（表格未变形）
- [ ] 关键实体无遗漏
- [ ] 结论有原文依据
- [ ] 对比维度一致
- [ ] 输出格式符合用户要求
- [ ] 无主观臆断替代原文事实

---

## 六、注意事项

- 超大文档（>500 页）分批次处理，每批输出阶段性结论
- 扫描件 PDF 优先使用 OCR 提取文字
- 多语言文档标注各段落语言
- 加密/权限文档提示用户解锁后重试
- 图片类文档以 OCR 结果为准，标注置信度
