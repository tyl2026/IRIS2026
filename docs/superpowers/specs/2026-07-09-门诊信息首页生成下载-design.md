# 门诊信息首页生成下载 — 设计文档

**日期**: 2026-07-09
**状态**: 已确认

---

## 1. 概述

将现有的 `web.HNYZDHCTYL7.ToExcel()` 方法封装为 HISUI 界面，支持：
- 按年月选择日期范围
- 自动生成 CSV 文件到后台 `/tmp/excel/`
- 展示后台已有 CSV 文件列表
- 选中文件下载到本地

## 2. 架构

```
dhcmrinfopagedownload.csp          ← 前端页面
        │ $cm()
        ▼
web.YZSY.DHCMRInfoPageDownLoad.cls ← 后端业务类
        │ $zf(-1) / %File
        ▼
/tmp/excel/                        ← Linux 文件系统
```

## 3. 后端类: web.YZSY.DHCMRInfoPageDownLoad.cls

### 固定常量（硬编码）

| 常量 | 值 |
|------|-----|
| ClassName | `EMRservice.HISInterface.OEPInfoPageInterface` |
| QueryName | `GetOutpatientList` |
| ExcelTitle | 文档中的完整字段码字符串 |
| OutputDir | `/tmp/excel/` |

### 方法

#### 3.1 GenerateCSV(YearMonth As %String) As %String

- 入参: `YearMonth` = `"2026-06"` 格式
- 解析出月初 (`2026-06-01`) 和月末 (`2026-06-30`)
- 调用 `GetOutpatientList` Query 获取数据
- 生成 CSV 到 `/tmp/excel/门诊信息首页_2026-06.csv`
- 文件名格式: `门诊信息首页_{YYYY-MM}.csv`
- 返回 JSON: `{ "success": true, "fileName": "门诊信息首页_2026-06.csv" }`

#### 3.2 ListFiles() As %String

- 遍历 `/tmp/excel/` 目录
- 筛选前缀为 `门诊信息首页_` 的 `.csv` 文件
- 返回 JSON 数组:
  ```json
  [
    { "name": "门诊信息首页_2026-06.csv", "size": "12.5KB", "date": "2026-07-09 08:31:43" }
  ]
  ```

### 前端 JS: dhcmrinfopagedownload.js

| 函数 | 触发 | 逻辑 |
|------|------|------|
| `loadFileList()` | 页面加载、生成完成后 | `$cm(ListFiles)` → 加载到 datagrid |
| `generateCSV()` | 点击"生成文件" | 取年月值 → `$cm(GenerateCSV)` → 成功则 `loadFileList()` |
| `downloadFile(name)` | 点击 datagrid 下载按钮 | 跳转下载链接下载文件 |

### 数据流

1. 用户选年月 → 点"生成" → `$cm({MethodName:"GenerateCSV", YearMonth:"2026-06"})` → 后端生成 CSV → 成功后 `loadFileList()`
2. 页面加载 → `loadFileList()` → `$cm({MethodName:"ListFiles"})` → 返回文件列表
3. 下载 → `window.location.href = "下载CSP路径?file=文件名"` 触发浏览器下载

## 6. 约束与注意事项

- CSP/JS 文件必须带 BOM (`utf-8-sig`)
- CLS 文件不带 BOM (`utf-8`)
- 前端使用 HISUI 组件 (`hisui-datebox`, `hisui-datagrid`, `hisui-linkbutton`)
- 事件绑定统一用内联 `onclick` 属性
- JS 逻辑放在外部文件，CSP 不内嵌 `<script>` 块
- 文件下载需要处理 CSP 代理或直接文件路径访问
- 命名空间运行时切换到 `DHC-APP`
