# iMEDWAY 协同网日报/周报自动化填写经验总结

## 一、三种报表对比

| 维度 | 日报 | 个人周报 | 项目周报 |
|------|------|----------|----------|
| **填写页URL** | `ProGroupWeek/UIProGroupAcitvewrite.aspx` | `WeekReport/UIWeeklyReport.aspx?modefiytime={date}` | `WeekReportPM/UIProjectReport.aspx?modefiytime={date}&bjType=bj` |
| **补交截止** | 无限制 | 每月10号 | 每月6号 |

| **时间粒度** | 每天 | 每周（周一） | 每周（周一） |
| **填写行数** | 5时段（4固定+1动态） | 自动生成 | 2个文本域（本周+下周） |
| **审批流程** | 无 | iframe审批弹窗→确认→完成 | 直接提交→确认→完成 |
| **项目阶段** | 无 | 无 | 需手动选"运维阶段" |
| **日志文件** | `submit_log.json` | `submit_log.json` | `proj_weekly_log.json` |
| **Skill** | `imedical-dailyreport` | `imedical-weeklyreport` | `imedical-project-weekly` |

## 二、核心自动化模式

### 2.1 Playwright 登录模式

```python
await page.goto(LOGIN_URL, wait_until="networkidle")
if "Login" in page.url:
    for i in range(120):  # 等2分钟
        await asyncio.sleep(1)
        if "Login" not in page.url: break
```

### 2.2 easyUI 组件操作

| 组件 | 读值 | 设值 | 点击 |
|------|------|------|------|
| datebox | `$('#x').datebox('getValue')` | `$('#x').datebox('setValue','yyyy-mm-dd')` | `.click()` |
| combobox | `$('#x').combobox('getValue')` | `$('#x').combobox('setValue', val)` | — |
| combogrid | `$('#x').combogrid('getValue')` | `$('#x').combogrid('setValue', id)` | — |
| textbox | — | `$('#x').textbox('setValue', text)` ⚠️ | — |
| timespinner | `$('#x').timespinner('getValue')` | `$('#x').timespinner('setValue', 'HH:MM')` | — |
| datagrid | `$('#x').datagrid('getData')` | — | — |

> ⚠️ **关键坑**：easyui-textbox 包裹原始 textarea，不能用 `element.value =` 或 `page.fill()`，必须用 `$('#id').textbox('setValue', text)`。

### 2.3 iframe 操作

```python
# 查找包含特定元素的 iframe
for f in page.frames:
    has = await f.evaluate('() => { return !!document.getElementById("targetId"); }')
    if has:
        await f.evaluate('() => { $("#targetId").textbox("setValue", "content"); }')
```

### 2.4 弹框处理

```python
# 通用 messager 弹框关闭
await page.evaluate('''() => {
    var m = document.querySelector(".messager-window");
    if (m && m.offsetParent !== null) {
```

### 2.5 异步等待模式

```python
# 轮询等待 easyUI 组件数据加载完成
result = await page.evaluate('''() => {
    return new Promise((resolve) => {
        var n = 0;
        function check() {
            n++;
            var data = $('#grid').datagrid('getData');
            if (data && data.rows && data.rows.length > 0) { resolve(data.rows); return; }
            if (n > 60) resolve([]);
            else setTimeout(check, 200);
        }
        check();
    });
}''')
```

### 2.6 日报预检（不导航查询页）

## 三、易错点

### 3.1 内容填入

- **easyUI textbox**：必须用 `textbox('setValue')`，不能用 `element.value` 或 `page.fill()`
- **隐藏 input 同步**：easyUI textbox 有隐藏 input（`name=txtThisContent`），textarea 的值需要通过 textbox API 设置才会同步
- **中文编码**：Windows 控制台 GBK 编码会导致打印乱码，保存到文件用 UTF-8 读取

### 3.2 日期格式

- 内容文件：`yyyymmdd` 8位，容错9位（`202604021`→`20260421`）
- 年份容错：`2024`→`2026`
- 协同网 API：`yyyy-mm-dd`

### 3.3 页面状态检测

- 个人周报：swid 为 0 表示未创建，非 0 表示已存在
- 按钮可见性：`offsetParent !== null` 判断（不是 `display !== 'none'`）
- 非工作日：`iswork=false` 时 `.workTr` 隐藏，需 `.show()` + `initWorkType()`

### 3.4 防重复

- 双层检查：页面 swid + 本地日志 JSON
- 日报：`findtasksave` API 返回 `IsSuccess`
- 周报：`BtnSubmit` 不可见 = 已提交

## 四、内容处理

### 4.1 去重

```python
def dedup(items):
    seen = set()
    for item in items:
        core = re.sub(r'[（(][^)）]*[)）]', '', item).strip()  # 去状态标记
        if core not in seen: seen.add(core); unique.append(item)
```

### 4.2 完成状态识别

- 已完成：无标记 或 含"已完成/已处理/已上线"
- 未完成：含"处理中/调试中/排查中/配置中/测试中..."
- 待处理：含"待更新/待处理/待提交"

### 4.3 项目分类

通过关键词匹配映射到项目模块：
```python
cats = [('医保智能审核', ['医保智能','3101','3102']), ...]
```

### 4.4 下周计划智能排除

本周未完成项 → 分类 → 与手动计划同分类的排除 → 剩余追加到下周。
