## pa_patmas（患者基本信息表）

- pa_patmas：患者基本信息表

## PA_Adm（患者就诊信息表）

- paadm_papmi_dr → pa_patmas（患者基本信息表）

## OE_Order（患者医嘱表，父表）

- OEORD_Adm_DR → PA_Adm（患者就诊信息）

## OE_OrdItem（患者医嘱明细表，OE_Order 的子表）

- oeori_oeord_parref → OE_Order（父表，患者医嘱表）
- oeori_itmmast_dr → arc_itmmast（医嘱项表）
- oeori_orddept_dr → CT_Loc（患者所在科室）
- oeori_userdepartment_dr → CT_Loc（开医嘱科室）
- oeori_recdep_dr → CT_Loc（接收位置）
- oeori_itemstat_dr → oec_orderstatus（医嘱状态）
- oeori_doctor_dr → CT_CareProv（开医嘱医生）
- oeori_xctpcp_dr → CT_CareProv（停医嘱医生）
- oeori_priority_dr → OEC_Priority（医嘱优先级）
- oeori_phfreq_dr → PHC_Freq（医嘱频率）
- oeori_instr_dr → PHC_Instruc（医嘱用法）
- oeori_unit_dr → CT_UOM（医嘱等效单位）
- oeori_durat_dr → PHC_Duration（医嘱疗程）
- oeori_useradd → SS_User（开医嘱人）
- oeori_billed：记账状态（门诊）
  - TB = 未账单
  - B = 账单
- oeori_doseqty：医嘱用量（单次）
- oeori_phqtyord：医嘱用量（整日）
- oeori_qtypackuom：整包装数量
- oeori_sttdat：要求开始日期
- oeori_date：开医嘱日期

## OE_OrdExec（医嘱执行记录表，OE_OrdItem 的孙表）

- oeore_oeori_parref → OE_OrdItem（父表，医嘱明细表）
- oeore_exstdaste：要求执行日期
- oeore_exsttime：要求执行时间
- oeore_billed：记账状态（住院）
  - TB = 未账单
  - B = 账单
- oeore_dateexeduted：执行日期
- oeore_timeexecuted：执行时间
- oeore_order_status_dr → OEC_Order_AdminStatus（执行状态）
- oeore_ctpcp_dr → CT_CareProv（执行人）

## dhc_patientbill（账单表，父表）

- pb_adm_dr → PA_Adm（就诊信息）
- pb_patinstype_dr → PAC_AdmReason（医保类型）
- pb_totalamount：总费用
- pb_patientshare：应收费用
- pb_payedflag：记账状态
- pb_refundflag：红冲状态
- pb_originalbill_dr → dhc_patientbill（红冲的账单，指向原账单号）

## DHC_PatBillOrder（医嘱账单表，dhc_patientbill 的子表）

- pbo_pb_parref → dhc_patientbill（父表，账单表）
- pbo_arcim_dr → arc_itmmast（医嘱项表）
- pbo_oeori_dr → OE_OrdItem（医嘱明细表）
- pbo_billqty：计费数量
- pbo_refundqty：退费数量
- pbo_patientshare：应收费用
- pbo_totalamount：总费用

## dhc_patbilldetails（计费明细表，DHC_PatBillOrder 的孙表）

- pbd_pbo_parref → DHC_PatBillOrder（父表，医嘱账单表）
- pbd_tari_dr → DHC_TarItem（计费项表）
- pbd_billqty：计费数量
- pbd_totalamount：总费用
- pbd_patientshare：应收费用
- pbd_billdate：应记账日期
- pbd_billstatus：记账状态
- pbd_createdate：创建账单日期
