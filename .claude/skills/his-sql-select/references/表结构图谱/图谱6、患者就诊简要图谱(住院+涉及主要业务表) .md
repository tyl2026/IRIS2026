## 住院患者就诊流程及涉及的业务表（不包括反向流程：退费退药）

### 1. 新患者来住院

### 2. 办理住院手续 / 交押金

涉及表：
- DHC_CARDREF：患者卡表
- PA_PerSon / Pa_PatMas：患者基本信息表
- PA_Adm：就诊表
- INSU_Adminfo：医保就诊登记表（医保患者）
- dhc_sfprintdetail：押金表
- AR_Receipts / AR_RcptAlloc / AR_RcptPayMode：系统原押金计费三表

### 3. 病区护士分床、分配管床医生

涉及表：
- PA_Adm：就诊记录表
- PAC_Ward：病区表
- PAC_Bed：床位表
- PAC_Room：房间表

### 4. 医生下诊断、下医嘱（区分临时、长期、自备）

涉及表：
- MR_Adm / MR_Diagnos / MR_DiagType：诊断三表
- OE_Order / OE_OrdItem：医嘱表
- OE_OrdStatus：医嘱状态表
- OE_OrdExec：医嘱执行记录表

### 5. 护理单

涉及表：
- 护士审核核对发送药房

### 6. 用药医嘱

涉及表：
- 口服单 / 输液单 / 注射单 / 皮试单
- OE_OrdExec：护士执行表
- DHC_PHACollected / DHC_PHACollectItm：住院发药表
- DHC_PhaCollectOutDrug / DHC_PhaCollectOutDrugDet：出院带药发药表

### 7. 检查医嘱

涉及表：
- 医生填写检查申请单
- DHCRB_RegInfo：RIS 登记表
- DHCRB_Report：RIS 报告表
- 医技科室预约执行

### 8. 检验医嘱

涉及表：
- 检验单
- 检验标本送至检验科执行

### 9. 处置治疗

涉及表：
- 治疗单

### 10. 手术申请

涉及表：
- 手术医生填写手术申请单
- DHC_AN_OPArrange：手术安排表
- OR_Anaest_Operation：所行手术表
- OR_An_Oper_Assistant：手术助手表
- OR_Anaesthesia：麻醉表
- 麻醉师安排麻醉，录入麻醉药品
- 手术完毕手术室置完成，录入手术费用

### 11. 转科转区转医生转床

涉及表：
- PA_AdmTransaction：转科转区转医生转床表

### 12. 护士执行

涉及表：
- OE_OrdExec：护士执行表

### 13. 医生下出院医嘱并做医疗结算

涉及表：
- PA_Adm 表更新：
  - paadm_meddischdoc_dr：医疗结算医生
  - paadm_dischgdoc_dr：最终结算护士
  - 医疗结算日期、最终结算日期、病人状态

### 14. 护士做最终结算

涉及表：
- DHC_InvPrtzy：住院发票表
- DHC_InvprtzySub：住院费用子分类表
- 更新原押金计费三表：AR_Receipts / AR_RcptAlloc / AR_RcptPayMode
- INSU_Divide：医保拆解结算表（医保患者）
- 收费员的票据表

### 15. 患者住院完成准备出院

### 涉及的库存表（通用）

- DHC_INTRANS：台帐表
- DHC_OEDispensing：打包表
- INC_ItmLoc：科室库存表
- INC_ItmBat：批次库存表
- INC_ItmLcBt：科室批次库存表
- DHC_LocDailyTotal：科室库存日变动表
- DHC_LocBTDailyTotal：批次库存日变动表
