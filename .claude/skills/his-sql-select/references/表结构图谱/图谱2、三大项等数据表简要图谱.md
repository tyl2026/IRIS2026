## DHC_TarIC（住院费用大分类表）

- DHC_TarIC：住院费用大分类表

## DHC_TarInpatCate（住院费用子分类表）

- TARIC_TARTIC_DR → DHC_TarIC（父表，住院费用大分类）

## DHC_TarItem（计费项表，父表）

- tari_uom → CT_UOM（计费单位，药品不用）
- tari_subcate → ARC_ItemCat（收费子分类）
- tari_acctcate：会计子分类
- tari_outpatcate：门诊子分类
- tari_emccate：核算子分类
- tari_mrcate：病案子分类
- tari_inpatcate → DHC_TarInpatCate（住院子分类）
- tari_mcnew：新病案子分类

## CT_ConFac（单位转换系数表）

- ctcf_fruom_dr → CT_UOM（从单位 A）
- ctcf_touom_dr → CT_UOM（到单位 B）
- ctcf_factor：转换系数

## CT_UOM（单位表）

- CT_UOM：单位表

## ARC_BillGrp（账单大类表，父表）

- ARC_BillGrp：账单大类表

## OEC_OrderCategory（医嘱大类表）

- OEC_OrderCategory：医嘱大类表

## ARC_BillSub（账单子分类表，ARC_BillGrp 的子表）

- ARCSG_ARCBG_ParRef → ARC_BillGrp（父表，账单大类）

## ARC_ItemCat（医嘱子分类表）

- ARCIC_OrdCat_DR → OEC_OrderCategory（医嘱大类）

## ARC_Alias（医嘱项别名表）

- alias_arcim_dr → arc_itmmast（医嘱项表）
- alias_text：医嘱别名
- alias_arcos_dr → ARC_OrdSets（医嘱套表）

## ARC_OrdSets（医嘱套总表）

- ARC_OrdSets：医嘱套总表

## arc_itmmast（医嘱项表）

- ARCIM_ItemCat_dr → ARC_ItemCat（医嘱子分类）
- ARCIM_BillSub_Dr → ARC_BillSub（账单子分类）
- ARCIM_PHCDF_DR → PHC_DrgForm（药学剂型）
- ARCIM_BillingUOM_DR → CT_UOM（计价单位）
- ARCIM_Generic_DR → PHC_Generic（通用名）
- ARCIM_OrderOnItsOwn：是否独立医嘱
- ARCIM_AllowOrderWOStockCheck：无库存医嘱

- PHC_Generic：通用名表

- APC_Vendor：供应商表

## INC_StkCat（库存分类表）

- INC_StkCat：库存分类表

## DHC_TarItemPrice（计费项价格表，DHC_TarItem 的子表）

- tp_tari_parref → DHC_TarItem（父表，计费项）
- tp_patinstype：患者医保类型，一般为自费
- tp_startdate：计费价格开始日期
- tp_price：计费项价格

## DHC_OrderLinkTar（医嘱表计费关联表）

- olt_arcim_dr → arc_itmmast（医嘱项）
- olt_tariff_dr → DHC_TarItem（计费项）
- olt_qty：医嘱项对应计费项的数量

## INC_ITM（库存项表）

- inci_ctuom_dr → CT_UOM（库存项单位）
- INCI_OriginalARCIM_DR → arc_itmmast（医嘱项）
- inci_ctuom_purch_dr → CT_UOM（采购单位）
- inci_finalvendor_dr → APC_Vendor（供应商）
- inci_inctg_dr → INC_StkTkGp（盘点分类）
- inci_incsc_dr → INC_StkCat（库存分类）

- phcd_phcsc_dr：药理子分类表
- phcd_phcpo_dr：毒麻表
- phcd_minsubcat_dr：药理学最小分类表
- PHCD_Generic_DR → PHC_Generic（通用名表）

## PHC_DrgForm（药学剂型表，PHC_DrgMast 的子表）

- PHCDF_PHCD_Parref → PHC_DrgMast（父表，药学项）
- PHCDF_PHCF_DR → PHC_Form（剂型表）
