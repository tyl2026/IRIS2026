## pa_patmas（患者基本信息表）

- pa_patmas：患者基本信息表

## DHC_CardRef（一卡通卡表）

- cf_papmi_dr → pa_patmas（患者基本信息）
- cf_user_dr → SS_User（建卡人）
- cf_cardtype_dr → DHC_CardTYpeDef（卡类型表）
- cf_cardinvprt_dr → DHC_CardInvPrt（卡费发票表）
- CF_AccNo_dr → DHC_AccManager（账户表）

## DHC_CardTYpeDef（卡类型表）

- DHC_CardTYpeDef：卡类型表

## DHC_CardInvPrt（卡费用发票表）

- DHC_CardInvPrt：卡费用发票表

## DHC_AccManager（患者账户信息表，父表）

- accm_papmi_dr → pa_patmas（患者基本信息表）
- accm_accstatus：账户状态
- accm_balance：账户余额
- accm_credtype_dr → DHC_CredType（证件类型）
- accm_credno：证件号码

## DHC_AccPreDeposit（门诊预交金表，DHC_AccManager 的子表）

- accpd_parref → DHC_AccManager（父表，患者账户信息表）
- accpd_type：预交金类型
- accpd_user_dr → SS_User（收款人）
- accpd_presum：金额
- accpd_left：当时账户剩余

## DHC_AccPrePayMode（预交金支付方式表，DHC_AccPreDeposit 的孙表）

- appm_accpd_parref → DHC_AccPreDeposit（父表，门诊预交金表）
- appm_paymode_dr → CT_PayMode（支付方式指针）

## DHC_AccPayList（消费明细表，DHC_AccManager 的子表）

- accpl_parref → DHC_AccManager（父表，患者账户信息表）
- accpl_papmi_dr → pa_patmas（患者基本信息表）
- accpl_invprt_dr → DHC_INVPRT（门诊发票表）
- accpl_user_dr → SS_User（操作员）
- accpl_paynum：支付金额
- accpl_left：当时账户余额

## DHC_INVPRT（门诊发票表，父表）

- prt_acount：票据费用
- prt_inv：发票号（一卡通中多数为空）
- prt_arrcp_dr：押金收据指针
- prt_dhcinvprtr_dr：发票重打指针
- prt_flag：票据状态
- prt_papmi_dr → pa_patmas（患者基本信息表）
- prt_useinvtype：发票类型（O = 门诊）
- prt_usr → SS_User（发票打印人）
- prt_accpinv_dr → DHC_AccPayINV（集中打印发票表）
- prt_instype_dr → PA_AdmReason（票据医保类型）
- prt_insdiv_dr → INSU_Divide（医保分解表）
- prt_fairtype：票据类型（F = 一般收费，R = 挂号）
- prt_refundreason：退费原因
- prt_ybpaysum：医保支付额
- PRT_initInv_DR → DHC_INVPRT（指向原作废发票 rowid）

## DHC_INVPayMode（发票支付方式表，DHC_INVPRT 的子表）

- ipm_prt_parref → DHC_INVPRT（父表，门诊发票表）
- ipm_paymode_dr → CT_PayMode（支付方式）
- ipm_cmbank_dr → CMC_BankMas（支付银行）
- ipm_amt：支付金额
- ipm_accpl_dr → DHC_AccPayList（指向卡消费明细表）

## DHC_AccPayINV（卡支付集中打印发票表，父表）

- api_amount：金额
- api_flag：票据状态
- api_puser_dr → SS_User（票据打印人）
- api_invno：发票号
- pai_papmi_dr → pa_patmas（患者基本信息表）
- api_accman_dr → DHC_AccManager（患者账户表）
- api_insdiv_dr → INSU_Divide（医保分解表）
- api_instype_dr → PA_AdmReason（患者医保类型）
- api_selfybpay：自费医保支付额

## DHC_AccPayINVMode（卡支付集中打印发票支付方式表，DHC_AccPayINV 的子表）

- apm_api_parref → DHC_AccPayINV（父表，卡支付集中打印发票表）
- apm_paymode_dr → CT_PayMode（支付方式）
- apm_cmbankdr → CMC_BankMas（银行）
- apm_amt：金额

## DHC_BillConINV（门诊发票与账单挂接表）

- dhcbci_admdr → PA_Adm（患者就诊信息表）
- dhcbci_invdr → DHC_INVPRT（门诊发票表）
