## pa_patmas（患者基本信息表）

- papmi_sex_dr → CT_Sex（性别表指针）
- papmi_dvanumber：记录身份证号
- papmi_userupdate → SS_User（更新用户）
- papmi_cardtype_dr → PAC_CardType（证件类型）
- 注：pa_patmas 表与 pa_person 表的 rowid 相同（兄弟表）

## pa_person（患者信息主表）

- paper_sex_dr → CT_Sex（性别）
- paper_country_dr → CT_Country（国籍）
- paper_nation_dr → CT_Nation（民族）
- paper_socialstatus_dr → CT_SocialStatus（社会地位/医保类型）
- paper_papmi_dr → pa_patmas（患者基本信息）

## MR_Adm（主诊断记录表，父表）

- MR_Adm：主诊断记录表

## mr_diagnos（患者诊断表，MR_Adm 的子表）

- mrdia_mradm_parref → MR_Adm（父表，主诊断记录）
- mrdia_icdcode_dr → MRC_ICDDx（诊断代码）
- mrdia_doccode_dr → CT_CareProv（诊断医生）
- mrdia_diagstat_dr → MRC_DiagnosStatus（诊断状态）
- mrdia_updateuser_dr → SS_User（更新用户）
- mrdia_usercreated_dr → SS_User（创建用户）

## MR_DiagType（诊断类型表，mr_diagnos 的孙表）

- TYP_ParRef → mr_diagnos（父表，诊断表）
- TYP_MRCDiagTyp → MRC_DiagnosType（诊断类型）

## PA_Adm（就诊记录表）

- paadm_papmi_dr → pa_patmas（患者基本信息表）
- paadm_depcode_dr → CT_Loc（就诊科室）
- paadm_admdoccodedr → CT_CareProv（就诊医生）
- paadm_dischgdoc_dr → CT_CareProv（最终结算护士）
- paadm_meddischdoc_dr → CT_CareProv（医疗结算医生）
- paadm_createuser → SS_User（挂号人）
- paadm_admreason_dr → PA_AdmReason（就诊医保类型）
- paadm_mainmradm_dr → MR_Adm（主诊断记录）
- paadm_currentroom_dr → PAC_Room（房间指针）
- paadm_currentward_dr → PAC_Ward（病区指针）
- paadm_currentbed_dr → PAC_Bed（床位指针）
- paadm_admdate：就诊（挂号）日期
- paadm_type：就诊类型
  - O = 门诊
  - I = 住院
- paadm_visitstatus：就诊状态
  - A = 正常
  - C = 取消
  - D = 出院

## DHC_CardRef（患者卡表）

- cf_papmi_dr → pa_patmas（患者基本信息）
- cf_user_dr → SS_User（建卡人）
- cf_cardtype_dr → DHC_CardTYpeDef（卡类型表）
- cf_cardinvprt_dr → DHC_CardInvPrt（卡费发票表）
- CF_AccNo_dr → DHC_AccManager（账户表）
