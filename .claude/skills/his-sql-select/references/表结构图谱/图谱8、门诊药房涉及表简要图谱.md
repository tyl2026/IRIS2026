## pa_patmas（患者基本信息表）

- pa_patmas：患者基本信息表

## oe_orditem（医嘱表）

- oe_orditem：医嘱表

## dhc_invprt（门诊结算票据表）

- dhc_invprt：门诊结算票据表

## DHC_PHDISPEN（门诊发药表，父表）

- phd_prt_dr → dhc_invprt（发票表指针）
- phd_papmi_dr → pa_patmas（患者基本信息）
- phd_php_pydr → DHC_PHPERSON（配药人）
- phd_php_fydr → DHC_PHPERSON（发药人）
- phd_pyflag：配药标志
- phd_fyflag：发药标志
- phd_phl_dr → DHC_PHLOC（药房）
- phd_phw_dr → DHC_PHWINDOW（窗口）
- phd_printflag：打印标志
- phd_prescno：处方号

## DHC_PHDISITEM（门诊发药子表，DHC_PHDISPEN 的子表）

- phdi_phd_parref → DHC_PHDISPEN（父表，门诊发药表）
- phdi_qty：发药数量
- phdi_payamount：发药金额
- phdi_oeori_dr → oe_orditem（医嘱表）
- phdi_retqty：退药数量
- phdi_price：售价

## DHC_PHARWIN（门诊药房业务入口表）

- 药品收费的同时会向该表写入发药信息
- pha_prt_dr → dhc_invprt（发票表指针）
- pha_phw_dr → DHC_PHWINDOW（窗口指针）
- pha_phl_dr → DHC_PHLOC（药房指针）
- pha_finflag：结束标志
- pha_printflag：打印标志
- pha_retfalg：退药标志
- pha_prescno：处方号

## DHC_PHLOC（药房表）

- DHC_PHLOC：药房表

## DHC_PHWINDOW（发药窗口表）

- DHC_PHWINDOW：发药窗口表

## DHC_PHPYWIN（配药窗口表，父表）

- phpy_phl_dr → DHC_PHLOC（药房）
- phpy_doflag：在用标志

## dhc_phpywinsub（药房与配药窗口对照表，DHC_PHPYWIN 的子表）

- phpys_phpy_parref → DHC_PHPYWIN（父表，配药窗口表）
- phpys_phw_dr → DHC_PHWINDOW（发药窗口）

## DHC_PHWPER（药房与发药窗口对照表）

- phwp_phw_dr → DHC_PHWINDOW（窗口）
- phwp_phl_dr → DHC_PHLOC（药房）
- phwp_doflag：在用标志

## DHC_PHPERSON（药房人员表）

- php_phl_dr → DHC_PHLOC（药房指针）
- php_ssusr_dr → SS_User（用户人员表）
- php_pyflag：配药标志
- php_fyflag：发药标志
- php_useflag：在用标志

## DHC_PHRETURN（退药表，父表）

- phret_phl_dr → DHC_PHLOC（药房）
- phret_prt_dr → dhc_invprt（发票表指针）
- phret_inv：发票号
- phret_phd_dr → DHC_PHDISPEN（指向发药表）
- phret_php_dr → DHC_PHPERSON（药房人员表）
- phret_rfr_dr → BLC_ReasonForRefund（退药原因）
- phret_newprt_dr → dhc_invprt（半退时指向新的发票表）

## DHC_PHRETITM（退药子表，DHC_PHRETURN 的子表）

- phrti_phret_parref → DHC_PHRETURN（父表，退药表）
- phrti_oeori_dr → oe_orditem（医嘱表）
- phrti_retqty：退药数量
- phrti_unit_dr → CT_UOM（退药单位）
- phrti_amount：退药金额
- phrti_price：售价
- phrti_phdi_dr → DHC_PHDISITEM（指向发药表）
- phrti_rp：进价
- phrti_rpamt：金额进价

- BLC_ReasonForRefund：退药原因表
