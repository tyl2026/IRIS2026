# 手术申请界面各个元素存储位置

备注：EpisodeID 为就诊表 PA\_Adm 的 ID

 anaSub 为麻醉表 OR\_Anaesthesia 的 Childsub

 anaopSub 为手术表 OR\_Anaest\_Operation 的 Childsub

 opaId 为手术排班表 DHC\_AN\_OPArrange 的 ID

adm = $P (^DHCANOPArrange( opaId),"^",1), admId = adm //adm 为手术排班表的一个指向就诊表的外键

EpisodeID = $P (^DHCANOPArrange( opaId),"^",1)

anaId = $P (^DHCANOPArrange( opaId),"^",2)

anaSub = $P ( anaId,"\|\|",2)

anaopSub = $O (^OR( adm,"ANA", anaSub,"OP", anaopSub))

s admId=$P(^DHCANOPArrange(opaId),"^",1)

 s papmiId=$p($g(^PAADM(admId)),"^",1)

 s paadmtype=$p($g(^PAADM(admId)),"^",2)

 s regNo=$p($g(^PAPER(papmiId,"PAT",1)),"^",1) // 登记号

涉及到表的关系如下：

主表：PA\_ADM（就诊表）

一级子表：OR\_Anaesthesia（麻醉表）

二级子表：OR\_Anaest\_Operation（手术表）

三级子表：OR\_An\_Oper\_Assistant（手术助手表）

 OR\_An\_Oper\_Anaest\_Assistant（麻醉助手表）

 OR\_An\_Oper\_Scrub\_Nurse （器械护士）

 OR\_An\_Oper\_Circul\_Nurse（巡回护士）

手术排班表 DHC\_AN\_OPArrange 中有个指向麻醉表 OR\_Anaesthesia 的指针，即为 OPA\_Anaest\_Dr；手术排班表中字段 OPA\_Status 为手术状态，包括以下几种状态：

Apply\|\|A：申请

Decline\|\|D：拒绝

Receive\|\|R：安排

InRoom\|\|I：术中

LeaveRoom\|\|L：术毕

Finish\|\|F：完成

NotApp\|\|N：非预约

PACU\|\|P：恢复

Operate\|\|O：

与医嘱表的关系：OE\_OrdItem 有对麻醉表的指针字段 OEORI\_Anaest\_DR，且存在该字段的索引 ^OEORDi(0,"Ana", OEORI\_Anaest\_DR, OE\_Order. OEORD\_RowId, OEORI\_Childsub)

其中，OE\_OrdItem 是表 OE\_Order 的子表；从我们手术列表界面切换至医嘱录入界面时，就会产生该医嘱指针；

SELECT * FROM SQLUser. OR\_Anaest\_Operation WHERE ANAOP\_Par\_Ref='1739119\|\|1'

SELECT * FROM OR\_An\_Oper\_Assistant WHERE OPAS\_ParRef='1739119\|\|1\|\|1'

SELECT * FROM SQLUser. DHC\_AN\_OPArrange WHERE OPA\_Adm\_Dr=1739119

SELECT * FROM SQLUser. DHC\_AN\_OPArrange WHERE OPA\_Anaest\_Dr='1739119\|\|1'
