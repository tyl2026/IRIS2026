## 门诊患者就诊流程及涉及的业务表（不包括反向流程：退费退药）

### 1. 新患者来就诊

### 2. 建卡、充值预交金

涉及表：
- DHC_CARDREF：患者卡表
- PA_PerSon / Pa_PatMas：患者基本信息表
- DHC_AccManager：账户管理表
- DHC_AccPreDeposit / DHC_AccPrePayMode：预交金表
- AR_Receipts / AR_RcptAlloc / AR_RcptPayMode：系统原押金计费三表

### 3. 预约挂号

涉及表：
- DHCBeforeReg：预约表

### 4. 挂号、取号

涉及表：
- PA_Adm：就诊记录表
- OE_Order / OE_OrdItem / OEC_OrderStatus：医嘱表
- DHC_ACCPayList：消费记录表
- DHCQueue：分诊叫号表
- MR_Adm：诊断主表
- INSU_Adminfo：医保就诊登记表（医保患者）

### 5. 分诊、叫号

涉及表：
- DHCQueue：分诊叫号表

### 6. 医生就诊、下诊断、下医嘱（多种医嘱类型）

涉及表：
- MR_Adm / MR_Diagnos / MR_DiagType：诊断三表
- OE_Order / OE_OrdItem：医嘱表
- OE_OrdStatus：医嘱状态表
- OE_OrdExec：医嘱执行记录表

### 7. 检查医嘱

涉及表：
- DHCRB_RegInfo：RIS 登记表
- DHCRB_Report：RIS 报告表
- 医技科室扣费、预约执行

### 8. 检验医嘱

涉及表：
- 门诊采血扣费
- 检验科室执行

### 9. 药物医嘱（皮试类）

涉及表：
- 输注室皮试
- OE_OrdExec：护士执行表

### 10. 药物医嘱（非皮试类）

涉及表：
- 药房扣费取药
- DHC_PHARWIN：取药窗口表
- DHC_PHDISPEN / DHC_PHDISITEM / DHC_PHDISITMCLB：门诊发药表
- DHC_INTRANS：台帐表
- DHC_OEDispensing：打包表
- INC_ItmLoc / INC_ItmBat / INC_ItmLcBt：科室库存表 / 批次库存表 / 科室批次库存表
- DHC_LocDailyTotal / DHC_LocBTDailyTotal：科室库存 / 批次库存日变动表

### 11. 治疗医嘱

涉及表：
- 治疗科室扣费执行

### 12. 口服类 / 注射输液类

涉及表：
- 输液室收费执行
- OE_OrdExec：护士执行表

### 13. 收费处集中打印发票、报销医保

涉及表：
- DHC_PatientBill / DHC_PatBillOrder / DHC_PatBillDetails：账单计费三表
- DHC_AccPayList / DHC_InvPrt（门诊发票）/ DHC_INVPayMode / DHCBillConINV（门诊发票与账单表关联表）：门诊一卡通业务表
- DHC_AccPayINV：集中打印发票表
- DHC_AccPayINVMode：发票支付方式表
- INSU_Divide：医保拆解结算表（医保患者）
- 收费员的票据表
