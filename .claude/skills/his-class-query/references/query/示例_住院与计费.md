## 1. 在院欠费

按病区和费别查询在院欠费病人，显示预缴金额与实际费用的差额（仅显示余额为负的病人）。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.tangkai","InPosArrears","95","1")`

**关键 Global**：
- `^PAADMi("NotCompl","I",ClinicalLocID,admId)` — 未完成的住院就诊索引
- `^CTLOC(0,"DepGrp",2,ClinicalLocID)` — 按科室组（临床科室=2）遍历科室
- `^PAADM(admId)` — 就诊信息（`^1`=病人 DR, `^6`=入院日期, `^7`=入院时间, `^9`=主管医生, `^20`=状态）
- `^PAPER(patId,"ALL")` — 病人基本信息（`^1`=姓名, `^7`=性别 DR）
- `^PAPER(patId,"PAT",1)` — 病人扩展（`^1`=住院号）
- `^PAC("ADMREA",PAAdmReason)` — 费别字典

**核心逻辑**：
```objectscript
// 按科室组遍历 → 取未完成住院就诊 → 计算预缴 vs 实际费用差额
f  s ClinicalLocID=$o(^CTLOC(0,"DepGrp",2,ClinicalLocID)) Q:ClinicalLocID=""  d
.f  s admId=$o(^PAADMi("NotCompl","I",ClinicalLocID,admId)) q:admId=""  d
..s prtpayamount=..GetAdmIdyjx(admId)   ; 预缴金额
..s PBPAY=..GetAdmIdPay(admId)           ; 实际费用
..i (prtpayamount>PBPAY) s balance=prtpayamount-PBPAY
..i (prtpayamount<PBPAY) s balance=-(PBPAY-prtpayamount)
..q:balance>="0"  ; 仅显示欠费（余额为负）
```

**ROWSPEC**：`"patName,IPNo,AdmReasonDesc,LocDesc,SexName,AdmData,AdmTime,DocDesc,prtpayamount:%Float,balance:%Float"`

## 2. 在院病人医嘱费用

按账单日期范围查询在院病人的医嘱级别计费明细（病人姓名、科室、医嘱名称、数量、金额）。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.RunQianQueryDemo","QueryCS5","2019-1-30","2019-1-30")`

**关键 Global**：
- `^DHCPB(0,"BILLDATE",BillDate,PatientBillId)` — 按账单日期索引
- `^DHCPB(PatientBillId)` — 账单主表（`^1`=就诊 DR）
- `^PAADM(PBAdmDr)` — 就诊信息（`^2`=类型, `^20`=状态）
- `^DHCPB(PatientBillId,"O",PBOChildSub)` — 账单医嘱子表（`^3`=医嘱项 DR, `^4`=医嘱 DR, `^5`=数量, `^8`=金额）
- `^ARCIM(+PBOARCIMDR,ARCIMVersion,1)` — 医嘱项（`^2`=名称）

**核心逻辑**：
```objectscript
f BillDate=startDate:1:endDate d
.s PatientBillId="" f  s PatientBillId=$o(^DHCPB(0,"BILLDATE",BillDate,PatientBillId)) q:PatientBillId=""  d
..q:(AdmType'="I")||(AdmVisitStatus'="A")  ; 仅在院住院
..s PBOChildSub=0 f  s PBOChildSub=$o(^DHCPB(PatientBillId,"O",PBOChildSub)) q:+PBOChildSub=0  d
...s ARCIMDesc=$p(^ARCIM(+PBOARCIMDR,ARCIMVersion,1),"^",2)
...s PBOToTalAmount=$p(^DHCPB(PatientBillId,"O",PBOChildSub),"^",8)
```

**ROWSPEC**：`"PatName,PatLOC,ARCIMDesc,PBOOEORIDR,PBOBillQty,PBOToTalAmount"`

## 4. 统计可用床位信息

列出所有激活状态的床位，显示病区名称、关联科室、床号、床位类型、床位费用医嘱项。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.RunQianQueryDemo","QueryBedInformation")`

**关键 Global**：
- `^PAWARD(WARDID)` — 病区（`^5`=科室 DR）
- `^CTLOC(LocationDR)` — 科室（`^2`=名称）
- `^CTLOC(LocationDR,"LINK",LINKChildsub)` — 科室关联（`^1`=关联科室 DR）
- `^PAWARD(WARDID,"BED",BEDsub)` — 床位子表（`^1`=床号, `^2`=类型 DR, `^4`=是否可用）
- `^PAC("BEDTP",BEDBedTypeDR)` — 床位类型字典（`^2`=类型名称）
- `^PAC("BEDTP",BEDBedTypeDR,"FEE",BEDTPIsub)` — 床位费用配置（`^2`=医嘱项 DR）

**核心逻辑**：
```objectscript
f  s WARDID=$o(^PAWARD(WARDID))  q:+WARDID=0  d
.s LocationDR=$p(^PAWARD(WARDID),"^",5)
.S BEDsub=""
.F  s BEDsub=$O(^PAWARD(WARDID,"BED",BEDsub)) Q:BEDsub=""  D
..s BEDRcFlag=$P(^PAWARD(WARDID,"BED",BEDsub),"^",4)
..q:BEDRcFlag'="Y"  ; 仅可用床位
..S BEDBedTypeDR=$P(^PAWARD(WARDID,"BED",BEDsub),"^",2)
..f  S BEDTPIsub=$o(^PAC("BEDTP",BEDBedTypeDR,"FEE",BEDTPIsub)) q:+BEDTPIsub=0  d
...s ARCIMDesc=$p(^ARCIM(+BEDTPIARCIMDR,BEDTPIARCIMsub,1),"^",2)
```

**ROWSPEC**：`"LocationName,LinkLocationNameNew,BEDCode,BEDBedTypeName,ARCIMDescNew"`

## 5. 统计所有在用床位所对应的医嘱项、代码、费用

遍历所有激活床位，关联其费用医嘱项和收费项目。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.RunQianQueryDemo","GetBedfee")`

**关键 Global**：
- `^PAWARD(WardRowId,"BED",Bedsub)` — 床位子表
- `^PAC("BEDTP",BedType,"FEE",BEDTPIChildsub)` — 床位费用配置（`^2`=医嘱项 DR）
- `^ARCIM(sub, ver, "1")` — 医嘱项（`^1`=代码, `^2`=名称）
- `^DHCOLT(OrdlinktarId)` — 医嘱项与收费项关联（`^1`=医嘱项 DR, `^2`=收费项 DR）
- `^DHCTARI(TarItemDr)` — 收费项目（`^2`=名称）

**核心逻辑**：
```objectscript
// 遍历病区 → 床位 → 床位费用配置 → 医嘱项 → 关联收费项
// 使用 ^TMPTK 临时 Global 去重
k ^TMPTK("web.RunQianQueryDemo","GetBedfee")
s WardRowId=0 f  s WardRowId=$o(^PAWARD(WardRowId)) q:WardRowId=""  d
.s Bedsub=0 f  s Bedsub=$o(^PAWARD(WardRowId,"BED",Bedsub)) q:Bedsub=""  d
..q:BedActiveFlag'="Y"
..s OrdlinktarId=0 f  s OrdlinktarId=$o(^DHCOLT(OrdlinktarId)) q:OrdlinktarId=""  d
...s TarItemDr=$p(^DHCOLT(OrdlinktarId),"^",2)
...s TarItemTemp=$p(^DHCTARI(TarItemDr),"^",2)
```

**ROWSPEC**：`"ArcItem,ArcItemCode,TarItem"`
