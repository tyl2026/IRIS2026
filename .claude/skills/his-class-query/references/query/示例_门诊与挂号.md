## 1. 门诊医生就诊人次

按日期范围统计每个科室、每个医生的门诊就诊人次（排除住院和已取消就诊）。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.RunQianQueryDemo","QueryDocJZRC","2019-02-01","2019-02-01","")`

**关键 Global**：
- `^PAADMi("PAADM_AdmDate", date, admId)` — 按就诊日期索引遍历
- `^PAADM(admId)` — 取就诊类型（`^2`=Type, `^4`=科室, `^9`=医生, `^20`=状态）
- `^CTPCP(patDocDr, 1)` — 医生姓名
- `^CTLOC(PAADMLOC)` — 科室名称

**核心逻辑**：
```objectscript
// 遍历日期范围内的就诊记录
f ADMDate=startDate:1:endDate d
.s ADMRowID=0
.f  s ADMRowID=$o(^PAADMi("PAADM_AdmDate",ADMDate,ADMRowID)) q:ADMRowID=""  d
..s AdmType=$p(^PAADM(ADMRowID),"^",2)
..q:(AdmType="I")||(AdmVisitStatus="C")  ; 排除住院和取消
..s patDocDr=$p(^PAADM(ADMRowID),"^",9)
..i patDocDr'=""  s ^TEMPJZRC($j,PAADMLOC,patDocDr)=$g(^TEMPJZRC($j,PAADMLOC,patDocDr))+1
```

**ROWSPEC**：`"patLOC,patDoc,JZRC:%Float"`

## 2. 门诊病人缴费信息

按日期范围查询门诊病人的缴费详情，包括自费金额、医嘱代码/名称、发票号、日期。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.CreateCardPatFee","Patientfees","2019-08-01","2019-08-31")`

**关键 Global**：
- `^PAADMi("PAADM_AdmDate", date, admId)` — 按就诊日期遍历
- `^DHCPB(0,"ADM", admId, PBId)` — 按就诊取账单
- `^DHCBCI(0,"Bill", PBId, BCIid)` — 账单关联发票
- `^DHCINVPRT(PRTRowid)` — 发票信息（`^14`=发票号, `^5`=日期）
- `^DHCPB(PBId,"O",ChildSub)` — 账单医嘱明细（`^11`=自费金额, `^3`=收费项, `^4`=医嘱ID）
- `^ARCIM(sub, ver, 1)` — 医嘱代码（`^1`）和名称（`^2`）

**ROWSPEC**：`"patName,OPNo,PBPay:%Float,OEORIDR,ARCCode,ARCName,PRTinv,PRTDate"`

## 3. 按诊断描述统计门诊科室就诊人次

按 ICD 诊断描述筛选，统计各门诊科室的就诊人次（按诊断次数计）。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.Yanghuan","QueryDiagnosInfo","2021-07-14","2021-07-14","37641")`

**关键 Global**：
- `^MRi("Date", MRDate, MRRowId)` — 按日期索引遍历病历
- `^MR(MRRowId,"DIA",MRChildsub)` — 诊断子表（`^1`=ICD 诊断 DR）
- `^MRC("ID",MRICDDR)` — ICD 诊断字典（`^2`=描述）
- `^MR(MRRowId,"DIA",MRChildsub,1)` — 诊断扩展（`^25`=开单科室 DR）

**核心逻辑**：
```objectscript
// 按日期遍历病历 → 遍历诊断子表 → 匹配 ICD 描述 → 按科室累加
f MRDate=startDate:1:endDate d
.s MRRowId="" f  s MRRowId=$o(^MRi("Date",MRDate,MRRowId)) q:MRRowId=""  d
..s MRChildsub="" f  s MRChildsub=$o(^MR(MRRowId,"DIA",MRChildsub)) q:MRChildsub=""  d
...s MRICDDR=$p(^MR(MRRowId,"DIA",MRChildsub),"^",1)
...q:(ICDDx'="")&&(ICDDx'=MRCIDDesc)  ; 匹配诊断描述
...i MRAddLocDr'="" s ^TEMPJZRC($j,MRAddLocDr)=$g(^TEMPJZRC($j,MRAddLocDr))+1
```

**ROWSPEC**：`"MRAddLoc,MZZLRC"`

## 4. 统计一段时间的挂号信息

查询挂号流水表，列出挂号时间、挂号医生、挂号员、就诊序号、发票号。

**调用方式**：`w ##Class(web.RunQianQueryDemo).TestSchedule("2019-04-15","2019-04-15")`

**类型**：ClassMethod（直接 `w` 输出，非 Query）

**关键 Global**：
- `^User.DHCRegistrationFeeI("RegDate", date, id)` — 按挂号日期索引
- `^User.DHCRegistrationFeeD(id)` — 挂号费持久化数据（`$listget` 取字段）
  - 字段 2 = 就诊号, 11 = 发票关联, 16 = 挂号时间, 17 = 挂号员 DR, 18 = 排班资源 DR
- `^RB("RES", +RegfecRBASDr)` — 排班资源（`^2`=医生 CTPCP DR）
- `^DHCINVPRT(+regTemp1)` — 发票（`^14`=发票号）

**核心逻辑**：
```objectscript
f date=StartDate:1:EndDate d
.s id=0 f  s id=$o(^User.DHCRegistrationFeeI("RegDate",date,id)) q:id=""  d
..s regTime=$listget(^User.DHCRegistrationFeeD(id),16)
..s docCtpcpDR=$p(^RB("RES",+RegfecRBASDr),"^",2)
..s docName=$p(^CTPCP(docCtpcpDR,1),"^",2)
```

## 5. 查询就诊病人所有的诊断及诊断类型

根据就诊号查询该病人的所有诊断（ICD 编码 + 自由文本描述）及诊断类型。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.RunQianQueryDemo","GetMRDiagnos","1")`

**关键 Global**：
- `^PAADM(Adm)` — 就诊记录（`^1`=病人 DR）
- `^MR(Adm,"DIA",MRDIAsub)` — 诊断子表（`^1`=ICD 诊断 DR）
- `^MR(Adm,"DIA",MRDIAsub,"DES",sub)` — 诊断自由文本描述
- `^MR(Adm,"DIA",MRDIAsub,"TYP",1)` — 诊断类型（`^1`=类型 DR）
- `^MRC("ID",MRDIAICDCodeDR)` — ICD 诊断字典（`^2`=描述）
- `^MRC("DTYP",TYPMRCDiagTyp)` — 诊断类型字典（`^2`=类型描述）

**ROWSPEC**：`"PAPMIName,DiagDesc,DTYPDesc"`
