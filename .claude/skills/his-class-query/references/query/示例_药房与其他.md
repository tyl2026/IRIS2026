## 1. 统计发药信息

按日期范围查询门诊发药记录，显示患者姓名、缴费时间、医嘱名称、发药数量、开单医生。

**调用方式**：`w ##Class(web.RunQianQueryDemo).DispensingInfo("2019-01-31","2019-01-31")`

**类型**：ClassMethod（直接 `w` 输出）

**关键 Global**：
- `^DHCPHDISPi("FYDATE",FYDate,PHDPHLDR)` — 按发药日期索引
- `^DHCPHLOC(PHDPHLDR)` — 药房科室（`^1`=科室 DR）
- `^DHCPHDISP(PHDROWID)` — 发药主表（`^7`=病人 DR, `^2`=发票 DR）
- `^DHCPHDI(PHDROWID,"PHDI",PHDISUB)` — 发药明细（`^4`=数量, `^5`=医嘱 DR）
- `^DHCINVPRT(PRTRowid)` — 发票（`^5`=日期, `^20`=时间）
- `^OEORD(+OEORIDR,"I",OEORIsub,1)` — 医嘱（`^2`=医嘱项 DR, `^11`=开单医生 DR）

**核心逻辑**：
```objectscript
f FYDate=StartDate:1:EndDate d
.s PHDPHLDR=0 f  s PHDPHLDR=$o(^DHCPHDISPi("FYDATE",FYDate,PHDPHLDR)) q:PHDPHLDR=""  d
..S PHDROWID=0 f  s PHDROWID=$o(^DHCPHDISPi("FYDATE",FYDate,PHDPHLDR,PHDROWID)) q:PHDROWID=""  d
...s PAPMI=$p(^DHCPHDISP(PHDROWID),"^",7)
...S PHDISUB="" F  s PHDISUB=$O(^DHCPHDI(PHDROWID,"PHDI",PHDISUB)) q:PHDISUB=""  D
....s PHDIQTY=$p(^DHCPHDI(PHDROWID,"PHDI",PHDISUB),"^",4)  ;数量
....s OEORIDR=$p(^DHCPHDI(PHDROWID,"PHDI",PHDISUB),"^",5)
....s ItmMastDesc=$p(^ARCIM(+ItmMastDR,ARCIMsub,1),"^",2)
```

## 2. 护士已审但药房未发的药品医嘱执行记录

查询指定日期范围内，护士已审核（领药类型="Y"）但药房未发药（状态="TC"）的药品医嘱执行记录。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.RunQianQueryDemo","QueryDrugExe","2021-6-2","2021-6-2","")`

**关键 Global**：
- `^OEORDi(0,"StDt",SttDate,OERowId,OEORIsub)` — 按医嘱开始日期索引
- `^OEORD(OERowId)` — 医嘱主表（`^1`=就诊 DR）
- `^OEORD(OERowId,"I",OEORIsub,1)` — 医嘱明细（`^2`=医嘱项 DR, `^13`=医嘱状态）
- `^ARCIM(+ItmMastDR,ARCIMsub,1)` — 医嘱项（`^2`=名称, `^10`=子分类 DR）
- `^ARC("IC",ItemCatDR)` — 医嘱子分类（`^7`=类型, "R"=药品）
- `^DHCOEDISQTY(0,"OEORI",OEORIRowId,DSPRowId)` — 按医嘱执行记录索引配药量
- `^DHCOEDISQTY(DSPRowId)` — 配药量（`^7`=状态, `^17`=类型, `^18`=审核日期, `^19`=审核时间）

**核心逻辑**：
```objectscript
f SttDate=startDate:1:endDate d
.s OERowId="" f  s OERowId=$o(^OEORDi(0,"StDt",SttDate,OERowId)) q:OERowId=""  d
..s OEORIsub="" f  s OEORIsub=$o(^OEORDi(0,"StDt",SttDate,OERowId,OEORIsub)) q:OEORIsub=""  d
...s OrderType=$p(^ARC("IC",ItemCatDR),"^",7)
...q:OrderType'="R"  ; 仅药品
...s DSPRowId="" f  s DSPRowId=$o(^DHCOEDISQTY(0,"OEORI",OEORIRowId,DSPRowId)) q:DSPRowId=""  d
....S OrderType=$p(^DHCOEDISQTY(DSPRowId),"^",17)
....Q:OrderType'="Y"           ; 仅护士已审核
....S DSPStatus=$p(^DHCOEDISQTY(DSPRowId),"^",7)
....q:DSPStatus'="TC"          ; 仅药房未发（TC=待发药）
```

**ROWSPEC**：`"PAPMIName,ItmMastDesc,DSPDateTime,OEORERowId,OEOREStatusDR,OEOREExStDateTime"`

## 3. 取输血医嘱相关数据

根据就诊号查询输血医嘱的名称、备注、扫码开始/结束日期时间、护士执行日期时间。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.Test","GetBloodOrd","173003476")`

**关键 Global**：
- `^OEORD(0,"Adm",Adm,OrderRowid)` — 按就诊取医嘱主表
- `^OEORD(OrderRowid,"I",OEORIsub,1)` — 医嘱明细（`^2`=医嘱项 DR, `^13`=状态 DR）
- `^OEORD(OrderRowid,"I",OEORIsub,"DEP",1)` — 医嘱备注
- `^OEORD(OrderRowid,"I",OEORIsub,"X",OEORESub)` — 执行记录（`^19`=执行日期, `^20`=执行时间）
- `^ARCIM(+OEORIItmMastDR,sub,1)` — 医嘱项（`^2`=名称）

**调用链**：Query 内调用 `##class(web.Test).BloodTime(OEORIRowId)` 获取扫码时间

**ROWSPEC**：`"arcdesc,OldNotes,BloodStartDate,BloodStartTime,BloodEndDate,BloodEndTime"`

## 4. 统计排过班的医生数据

列出所有有排班记录的医生，显示姓名、排班科室、默认科室、安全组、科室组、其他登录科室。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.RunQianQueryDemo","QueryCS2")`

**关键 Global**：
- `^RBAS(ASRESID)` — 排班资源
- `^RB("RES",ASRESID)` — 资源（`^1`=科室 DR, `^2`=医护人员 DR）
- `^SSU("SSUSR",0,"CTPCP",RESCTPCPDR,SSRowId)` — 按医护人员反查用户
- `^SSU("SSUSR",SSRowId)` — 用户（`^2`=姓名, `^4`=默认科室 DR, `^5`=安全组 DR, `^10`=其他登录科室）
- `^SSU("SSGRP",SSUSRGroup)` — 安全组（`^1`=组名）
- `^CTLOC(CTLOCDepDR)` — 科室（`^2`=名称, `^19`=科室组 DR）
- `^RBC("DEP",CTLOCDepDR)` — 科室组字典（`^2`=组名）

**核心逻辑**：
```objectscript
f  s ASRESID=$o(^RBAS(ASRESID))  q:+ASRESID=0  d
.s RESCTLOCDR=$p(^RB("RES",ASRESID),"^",1)
.s RESCTPCPDR=$p(^RB("RES",ASRESID),"^",2)
.s SSRowId=$O(^SSU("SSUSR",0,"CTPCP",RESCTPCPDR,SSRowId)) Q:SSRowId=""  D
.S SSNAME=$P(^SSU("SSUSR",SSRowId),"^",2)
```

**ROWSPEC**：`"SSNAME,RESCTLOCNAME,SSUSRDefaultDepDesc,GroupName,DEPDesc,SSUSRChangeLocation"`

## 5. 建卡患者信息

按日期范围查询建卡记录，显示卡号、建卡人、姓名、民族、生日、就诊次数。

**调用方式**：`d ##class(%ResultSet).RunQuery("web.RunQianQueryDemo","QueryCardPatInfo","2019-02-01","2019-02-01")`

**关键 Global**：
- `^DHCCARDi("CF",0,"Date",CFDate,CFRowID)` — 按建卡日期索引
- `^DHCCARD("CF",CFRowID)` — 就诊卡（`^2`=卡号, `^4`=病人 DR, `^8`=建卡时间, `^9`=建卡人 DR）
- `^SSU("SSUSR",CFUserDR)` — 用户（`^2`=姓名）
- `^PAPER(CFPAPMIDR,"ALL")` — 病人（`^1`=姓名, `^6`=出生日期）
- `^PAPER(CFPAPMIDR,"PER",2)` — 病人扩展（`^1`=民族 DR）
- `^CT("NAT",PANationDR)` — 民族字典（`^2`=民族名称）
- `^PAPERdr(CFPAPMIDR,"ADM",PAADMType,ADMRowID)` — 按病人遍历就诊记录（统计就诊次数）

**核心逻辑**：
```objectscript
f CFDate=startDate:1:endDate d
.s CFRowID="" f  s CFRowID=$o(^DHCCARDi("CF",0,"Date",CFDate,CFRowID)) q:CFRowID=""  d
..s CFCardNo=$p(^DHCCARD("CF",CFRowID),"^",2)
..s CFPAPMIDR=$p(^DHCCARD("CF",CFRowID),"^",4)
..; 统计就诊次数（排除已取消）
..s PAADMType="" f  s PAADMType=$o(^PAPERdr(CFPAPMIDR,"ADM",PAADMType)) q:PAADMType=""  d
...s ADMRowID="" f  s ADMRowID=$o(^PAPERdr(CFPAPMIDR,"ADM",PAADMType,ADMRowID)) q:ADMRowID=""  d
....q:AdmVisitStatus="C"
....S ADMJZCS=ADMJZCS+1
```

**ROWSPEC**：`"CFCardNo,CFUserName,PatName,CFDATETIME,PANationDesc,PAPMIbirthday,ADMJZCS"`
