## 发药（门诊 + 住院）

发药分两套表结构，查询时需明确场景：

**门诊发药**：
| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `DHC_PHDISPEN` | 门诊发药主表 | `PHD_PAPMI_DR` → PA_PatMas、`PHD_FYDATE`（发药日期）、`PHD_PHL_DR` → DHC_PHLOC（药房） |
| `DHC_PHDISITEM` | 门诊发药明细（子表） | `PHDI_PHDPARREF` → DHC_PHDISPEN、`PHDI_QTY`（数量）、`PHDI_OEORI_DR` → OE_OrdItem |

药品名称链路：`DHC_PHDISITEM.PHDI_OEORI_DR -> OE_OrdItem.OEORI_ItmMast_DR -> ARC_ItmMast.ARCIM_Desc`

**住院发药**：
| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `DHC_PHACollected` | 住院发药主表 | `DHC_PHACollectDate`（发药日期）、`DHC_PHALoc_DR` → CT_Loc、`DHC_PHAAdm_DR` → PA_Adm |
| `DHC_PHACollectItm` | 住院发药明细（子表） | `PHACI_Qty`（数量）、`PHACI_INCI_DR` → INC_Itm |

药品名称链路：`DHC_PHACollectItm.PHACI_INCI_DR -> INC_Itm.INCI_Desc`
病人信息链路：`DHC_PHACollected.DHC_PHAAdm_DR -> PA_Adm.PAADM_PAPMI_DR -> PA_PatMas.PAPMI_Name`
