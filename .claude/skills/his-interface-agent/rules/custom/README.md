# 自定义规则目录

本目录用于存放用户自定义的取值规则，优先级最高，永不自动覆盖。

## 规则来源

1. **L4 人工确认回流**：当 L1-L3 引擎无法匹配时，人工确认后自动写入
2. **手动添加**：用户根据项目需求手动编写
3. **项目特有规则**：特定项目的字段映射规则

## 文件格式

参考 `domains/` 目录下的规则文件格式：

```markdown
---
domain: "custom"
name: "自定义规则"
version: "1.0"
lastUpdated: "2026-05-10"
---

# 自定义规则

## 字段映射规则

### CUSTOM_FIELD_001

| 属性 | 值 |
|------|-----|
| 标准名 | `CUSTOM_FIELD_001` |
| 匹配模式 | 字段名1, 字段名2 |
| 取值表达式 | `$p($g(^Global(node)),"^",1)` |
| Global | `^Global` |
| 置信度 | 1.0 |

**说明**：自定义字段说明。

```objectscript
s CUSTOM_FIELD_001 = $p($g(^Global(node)),"^",1)
```
```

## 注意事项

1. **不要删除已有规则**：只添加新规则，不要修改或删除已有规则
2. **保持格式一致**：遵循 Markdown + YAML Frontmatter 格式
3. **添加说明**：每条规则必须有说明和取值代码示例
4. **置信度设为 1.0**：自定义规则表示已确认，置信度应设为 1.0

## 回流机制

当使用 L4 人工补全时，系统会自动：
1. 提示用户确认取值逻辑
2. 将确认结果写入本目录
3. 下次同类字段直接被 L1 命中
