## 描述

**高频复用的通用字段规则集**,几乎每个接口都会用到的"基建型"字段。这些字段的取值逻辑高度一致:

- **rowId**: 主键标识,通常直接取自接口入参的rowId
- **NAME / CODE**: 名称与编码,通过 `$p(dataRowId,"^",N)` 按位切割入参串获取
- **dATE / tIME**: 日期与时间,同上方式从入参串提取
- **sTATUS**: 状态标识,入参串提取或字典映射
- **rEMARK**: 备注说明,默认空字符串

> **设计原则**: 通用字段采用 `dataRowId` 入参统一切割模式,避免各接口重复定义取值逻辑. `dataRowId` 是典型的 `^` 分隔符拼接串(类似HIS全局变量的存储惯例).

## 字段映射规则

### ROW_ID

|| 属性 | 值 ||
|------|-----|------|
| 标准名 | `rowId` |
| 匹配模式 | ID, id, rowId, rowId, row_id |
| 描述关键词 | 编号, 标识, 主键, 行号, RowId, 唯一标识 |
| 取值表达式 | `rowId` |
| Global | `-` (无,直接取自方法入参) |
| 下标路径 | `-` |
| 置信度 | 0.95 |
| 命中次数 | 100 (几乎所有接口) |
| 来源 | `通用-跨域抽象` |

**说明**：

主键/行号标识,直接取自接口方法的 `rowId` 形参。这是最基础的字段,几乎每个Query/方法的第一步就是赋值ROW_ID。

```objectscript
s rowId = rowId
```

**使用示例**：
```objectscript
; 典型用法 — 作为输出行的第一个字段
s row = $lb(rowId, NAME, CODE, ...)
d ..RowSet(row)
```

### NAME

|| 属性 | 值 ||
|------|-----|------|
| 标准名 | `NAME` |
| 匹配模式 | NAME, name, mC, mc, 名称 |
| 描述关键词 | 名称, 名字, 描述, 标题, 姓名, 名称描述 |
| 取值表达式 | `$p(dataRowId, "^", 2)` |
| Global | `-` (来自入参串dataRowId) |
| 下标路径 | `-` |
| 置信度 | 0.9 |
| 命中次数 | 95 (绝大多数接口) |
| 来源 | `通用-跨域抽象` |

**说明**：

名称字段,从 `^` 分隔的入参串第2位切割。`dataRowId` 是HIS系统中常见的复合主键串格式,用 `^` 分隔多个属性值。

```objectscript
s NAME = $p(dataRowId, "^", 2)
```

**数据流示意**:
```
dataRowId = "1^张三^001^2024-01-01^..."
              ^ ^^^^
              | └── NAME ($p(...,"^",2))
              └── rowId ($p(...,"^",1))
```

**别名覆盖场景**:
- 在患者域(`01-user`)中,此位置对应患者姓名(hZXM)
- 在科室域中对应科室名称(kSMC)
- 在药品域中对应药品名称(yPMC)

| 标准名 | `CODE` |
| 匹配模式 | CODE, code, bM, bm, 编码, 代码 |
| 描述关键词 | 编码, 代码, 代号, 编号, Code, bM |
| 取值表达式 | `$p(dataRowId, "^", 3)` |
| Global | `-` (来自入参串dataRowId) |
| 下标路径 | `-` |
| 置信度 | 0.92 |
| 命中次数 | 98 (绝大多数接口) |
| 来源 | `通用-跨域抽象` |

**说明**：

编码/代号字段,从入参串第3位切割。与NAME成对出现,构成"编码-名称"标准二元组。

```objectscript
s CODE = $p(dataRowId, "^", 3)
```

**典型搭配模式**:
```objectscript
; CODE + NAME 总是相邻出现,分别占 ^3 和 ^2
s NAME = $p(dataRowId, "^", 2)   ; 名称
s CODE = $p(dataRowId, "^", 3)   ; 编码
```

### DATE

|| 属性 | 值 ||
|------|-----|------|
| 标准名 | `dATE` |
| 匹配模式 | dATE, date, rQ, rq, dATETIME, datetime |
| 描述关键词 | 日期, 时间, 日期时间, 日期戳 |
| 取值表达式 | `$p(dataRowId, "^", 4)` |
| Global | `-` (来自入参串dataRowId) |
| 下标路径 | `-` |
| 置信度 | 0.88 |
| 命中次数 | 80 (大多数含时间维度的接口) |
| 来源 | `通用-跨域抽象` |

**说明**：

日期字段,入参串第4位。注意: 此处为**原始日期值**(HIS内部格式或ODBC格式),如需转换为 `YYYY-MM-DD` 格式应使用 `$zd(dateVal, 3)` 进行格式化。

```objectscript
s dATE = $p(dataRowId, "^", 4)

; 如需格式化(常用):
s dateFmt = $zd($p(dataRowId, "^", 4), 3)  ; → "2024-01-01"
```

**⚠️ 格式注意**:
- HIS内部日期格式 = 整数(如 `670101` 表示2024-01-01,具体取决于$H基准)
- oDBC/显示格式 = `"2024-01-01"` 字符串
- 使用前确认目标平台要求的日期格式

### TIME

|| 属性 | 值 ||
|------|-----|------|
| 标准名 | `tIME` |
| 匹配模式 | tIME, time, sJ, sj, 时间 |
| 描述关键词 | 时间, 时间戳, 时分秒, 时间点 |
| 取值表达式 | `$p(dataRowId, "^", 5)` |
| Global | `-` (来自入参串dataRowId) |
| 下标路径 | `-` |
| 置信度 | 0.85 |
| 命中次数 | 70 (含精确时间要求的接口) |
| 来源 | `通用-跨域抽象` |

**说明**：

时间字段,入参串第5位。通常与DATE配合使用,共同构成完整的日期时间信息。

```objectscript
s tIME = $p(dataRowId, "^", 5)

; 常见拼接模式(参考zz-custom中的REPORT_DATETIME):
s dATETIME = $zd(dATE, 3)_"_"_$zt(tIME, 1)  ; → "2024-01-01_14:30:00"
```

**⚠️ 与DATE的关系**:
- DATE在 `^4`, TIME在 `^5`,两者总是相邻
- 上报场景中常需拼接为完整时间戳(下划线或空格分隔)
- `$zt(timeVal, 1)` 可将内部时间转为 `HH:MM:SS` 显示格式

## dataRowId 位序速查

通用字段遵循统一的入参串位序约定,便于记忆:

| 位置 | $p()参数 | 标准字段 | 类型 | 必填 |
|------|----------|---------|------|------|
| ^1 | `$p(...,"^",1)` | rowId | 主键 | ✅ 必须 |
| ^2 | `$p(...,"^",2)` | NAME | 名称 | ⚠️ 通常 |
| ^3 | `$p(...,"^",3)` | CODE | 编码 | ⚠️ 通常 |
| ^4 | `$p(...,"^",4)` | dATE | 日期 | ⚠️ 通常 |
| ^5 | `$p(...,"^",5)` | tIME | 时间 | ❌ 可选 |
| ^6 | `$p(...,"^",6)` | sTATUS | 状态 | ⚠️ 通常 |

> **记忆口诀**: "一号行号二名三码四日期五时六状态" — 123456 对应 rowId/NAME/CODE/dATE/tIME/sTATUS

## 踩坑提示

### 🔴 高频踩坑

| # | 坑点 | 影响 | 解决方案 |
|---|------|------|---------|
| c1 | **$p()位序搞混** | NAME拿到CODE,全错 | 严格按速查表:^1=ID ^2=NAME ^3=CODE |
| c2 | **日期格式未转换** | 上报平台拒收 | 统一用 `$zd(val,3)` 转YYYY-MM-DD |
| c3 | **TIME和DATE拆开上报** | 缺少完整时间戳 | 拼接: `$zd(d,3)_"_"_$zt(t,1)` |
| c4 | **REMARK留空字符串"" vs $c(0)** | 部分系统判空不一致 | 统一用 `""`,不用 `$c(0)` |

### 🟡 中频注意事项

| # | 要点 | 说明 |
|---|------|------|
| m1 | **dataRowId可能为空** | 入参校验:`i dataRowId="" q` |
| m2 | **$p()越界不报错** | 返回空串而非报错,需主动校验位數 |
| m3 | **STATUS语义因域而异** | 同是"1",医嘱域=执行,就诊域=在院,必须结合上下文 |

### 📐 设计原则

| # | 原则 | 说明 |
|---|------|------|
| d1 | **Parameter抽离** | 固定值禁止硬编码在 `$lb()` 中,必须通过类参数引用 |
| d2 | **防御性编程** | 所有 `$p()` 操作前先确认 dataRowId 非空 |
| d3 | **格式一致性** | 日期/时间统一走 `$zd()`/`$zt()`,禁止手动拼接 |
