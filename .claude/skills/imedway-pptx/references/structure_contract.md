## 1. Slide Type Hierarchy

按 4 大章节组织（与 TOC 一致）：

| 章节 | 类别 | 页型 |
|------|------|------|
| 01 基础样式 | Basic Styles | Progressive, Unified Form, Summary-Detail |
| 02 架构图样式 | Architecture | Pure architecture, Architecture + content, Point-title |
| 03 图表样式 | Charts & Tables | Formal charts, Vibrant charts, Data tables |
| 04 图片样式 | Image Showcase | Image + content, Image + summary, System screenshots |

**总数**: 4 大节 × 3 子节 = 12 类内容页 + 封面/目录/章节/结尾 = 15 类完整

**全局规则 (ALL slides)**:
- 背景: **白色 #FFFFFF**（无例外）
- 内容页右上: iMEDWAY logo
- 内容页左下: 6 块品牌方块（绿黄绿蓝蓝蓝）
- 章节页（00/01/02/03/04 切换）装饰方块在左下和右边
- **禁止**深色卡片底或灰底卡片 — 内容区保持开放白底

## 2. Cover Slide

> **封面只有 4 个元素 — 全部从模板复用，不要凭空添加**。
> 模板中没有照片拼贴 / Slogan / 彩块，那些是「可选增强」（见 SKILL.md 末尾「增强封面建议」）。

### Layout
- **背景**: 白色 #FFFFFF（CRITICAL）
- 封面仅占左半区（X ≤ 22cm），右半区留白
- **所有元素位置/尺寸**与模板 100% 一致（必复用）

### Elements（模板实测 4 项 — 不可增减）

| # | 元素 | 类型 | 位置 (cm) | 尺寸 (cm) | 用途 |
|---|------|------|-----------|-----------|------|
| 1 | iMEDWAY logo 图 | **PICTURE** | (3.08, 2.61) | 7.94 × 1.17 | **从模板原图复用**（1016×149 px PNG） |
| 2 | 主标题 | TEXT_BOX | (2.56, 6.11) | 18.28 × 2.27 | 46pt Bold 深蓝 #00479D |
| 3 | 副标题 | TEXT_BOX | (2.68, 8.48) | 10.13 × 1.37 | 26pt Regular 深蓝 #00479D |
| 4 | 提报人/时间 | TEXT_BOX | (2.68, 14.26) | 5.48 × 2.20 | 14pt 深灰 #262626 — 1 行/2 行均可 |

### 替换规则
- **logo 图（PICTURE）**: 不替换 — 永远复用模板里的 `assets/template.pptx` slide 1 的图片
- **主/副标题/提报块（TEXT_BOX）**: 占位符 → 用户内容（保持位置/尺寸/字号/字重/颜色）
- **背景**: 始终白底，**不**用模板的渐变或任何深色

### 复用方法（python-pptx）
```python
# 1) 从模板抽 logo 图
logo = shape.image.blob  # bytes
# 2) 写新页时 add_picture 用同一张图
slide.shapes.add_picture(logo_path, Cm(3.08), Cm(2.61),
                         width=Cm(7.94), height=Cm(1.17))
```

### 必查不变量
- 背景 = #FFFFFF
- 恰好 1 个 PICTURE + 3 个 TEXT_BOX（其它类型 = 越界）
- 主标题字号 = 46pt Bold

## 3. Table of Contents (TOC) Slide

### Layout
- **背景**: 白色 #FFFFFF
- **装饰**: 左上 + 右下 圆角方块

### Elements
1. **左列 (~30%)**:
   - 大号「目录」两字（深蓝，约 60pt）
   - 下方「CONTENTS」带下划线
2. **右列 (~70%)**:
   - 编号条目: 「01/ {标题}」「02/ {标题}」…
   - 编号格式: 两位前导零
   - 分隔: 「/」空格
   - 字体: 深蓝 Bold
3. **角装饰**:
   - 左上: 蓝实心 + 蓝边白底 圆角方块（堆叠）
   - 右下: 蓝边白底 + 蓝实心 圆角方块（堆叠）

## 4. Chapter Divider Slide

### Layout
- **背景**: 白色 #FFFFFF
- **装饰**: 左下阶梯图案 + 右边竖直方块列

### Elements
1. **节号**: 极大字号（如「01」），深蓝，居中偏左
2. **斜杠分隔符**: 「/」深蓝，置于节号后
3. **节标题**: 中号（如「基础样式模板」），深蓝，置于斜杠后
4. **居中规则**: 标题内容写完后，将「节号 + 斜杠 + 标题」作为整体**居中**（设计规范 1.6）

### Decorative Elements
- **左下**: 复杂阶梯状彩色方块（蓝/黄/绿）
- **右边**: 竖直方块列（典型: 蓝黄蓝黄蓝 + 绿黄绿）
- 方块比内容页 6 方块更小、更密

## 5. Content Slide - Progressive Layout (递进关系) — 1.1

### Use Case
展示层级/递进关系（金字塔结构）。

### Layout
- **背景**: 白色 #FFFFFF
- **标题栏**: 左上「1.1 {标题}」30pt Bold 深蓝
- **Logo**: 右上
- **左区 (~50%)**: 5-6 层堆叠梯形（金字塔）
- **右区 (~50%)**: 5-6 文本块（每块带左侧竖条）
- **左下**: 6 块品牌方块

### Elements
- 每个梯形包含一个标签（顶部 = 最高层）
- 文本块含: 竖色条（左）+ 标题 + 描述段
- 竖条颜色循环: 深蓝、浅蓝、黄、绿
- 正文: 18pt 深灰 #262626
- 实际尺寸: 梯形从顶 (4.13×3.66cm) 渐增到底 (11.7×3.81cm)

### 变体: 深色侧栏版
- **左区 (17.71×19.05cm)** 填充深蓝 #00479D（**只填左半区，不动背景**）
- 梯形在深色侧栏上以**白色/透明**叠加渲染
- 右侧文字保持白底 + 原色竖条
- **背景仍为白底**，深蓝只是侧栏色块

## 6. Content Slide - Unified Form Layout (形式统一) — 1.2

### Use Case
以统一卡片格式展示多个条目。

### Layout
- **背景**: 白色 #FFFFFF
- **网格**: **2×2**（4 象限，非 2×3）— 每象限约 13×6.5cm
- **每象限包含**:
  - 圆形图标（带色背景）+ 标题（顶部）
  - 内容区: 列表、描述、子卡片
  - 象限边框: 浅灰 #F2F2F2 或白底细线

### 卡片类型（实际模板中的 4 种变体 — 1.2 样式 1）

| 象限 | 标题内容 | 文字色 |
|------|----------|--------|
| 左上 | 「标题内容」 | 深蓝（默认） |
| 右上 | 「标题内容」 | 深蓝（默认） |
| 左下 | 「标题内容」 | 深蓝（默认） |
| 右下 | 「标题内容」 | 深蓝（默认） |

### 1.2 样式 2 变体（4 种颜色编码标题 — 4 色全 hex 必填）

| 象限 | 标题文字 | 标题颜色（hex） | 含义 |
|------|----------|----------------|------|
| 左上 | 「标题内容」 | **深蓝 #00479D** | 默认 |
| 右上 | 「标题内容（补充、提醒内容等）」 | **黄 #F8B62D** | 提醒/补充 |
| 左下 | 「标题内容」 | **深蓝 #00479D** | 默认 |
| 右下 | 「标题内容（警示性内容）」 | **橙 #ED7D31** | 警示 |
| （替换） | 「标题内容（安全性质等内容）」 | **绿 #13AE67** | 安全 |

> **4 色 hex 缺一不可**：所有 4 个变体的 hex 都要写出（默认深蓝最易漏）。用标题色变体表达**不同性质**内容，比单纯改背景更优。

### Color Coding
- 图标使用品牌色（蓝、绿、黄）于白底或浅底
- 项目背景: 白底细线 或 极浅灰 #F2F2F2 填充
- **整体幻灯片背景保持白底**

## 7. Content Slide - Summary-Detail Layout (总分样式) — 1.3

### 变体 1: 文字主导（1.3 样式 1）

- **背景**: 白
- **左区 (~45%)**: 大块总结区
  - 二级标题条（深蓝 #00479D 底 + 白字）
  - 18pt 正文段落
- **右区 (~55%)**: 2×2 详情卡
  - 每张卡: 小标题 + 正文段
  - 卡背景: 白底细线
  - **关键尺寸**: 每张详情卡 **5.85×5.85cm**（正方形），下方有标签

> **1.2 vs 1.3 关键区分**：
> - 1.2 形式统一: 4 象限**全部**内容，地位平等（无总结条）
> - 1.3 总分样式 变体 1: 左侧总结条 + 右侧 4 张 **5.85×5.85cm** 详情卡
> - 1.3 总分样式 变体 2: 顶部总结条 + 底部流程图（中央六边形节点 5.48×3.4cm + 两侧 6 圆形图标 3.61×1.14cm）

### 变体 2: 图形主导（1.3 样式 2）

- **背景**: 白
- **顶部 (~25%)**: 总结文字条（29.95×2.74cm）
- **底部 (~75%)**: 流程图
  - 中央六边形节点（深蓝 + 浅蓝）
  - 周围圆形图标（带连接线）
  - 外部节点有标签
  - 弯曲箭头表示流向

### 布局（变体 2 实测）
- 总结条: 顶部 (1.98, 3.35) 尺寸 29.95×2.74cm
- 中央节点: 2 个五边形/六边形 (10.65,10.1) 和 (16.71,10.08)，5.48×3.4cm
- 左右两列流程: 各 3 个圆形图标 (3.61×1.14cm) 标签
- 箭头: 弯曲连接（FREEFORM 形状）

### 实际层级 (实测尺寸)

```
┌─ 顶层分类区（top） ─────────────────────────────────────┐
│  [3.58-12.23cm 区域]   [12.44-18.32cm]  [18.51-26.2cm]   │
│  3 大类 box × 2 行子项（每行 3 项 = 2x3 grid）           │
└────────────────────────────────────────────────────────┘

┌─ 中层类别区（mid） ─────────────────────────────────────┐
│  [3.65cm]   [8.20cm]   [16.63cm]   [21.89cm]             │

└────────────────────────────────────────────────────────┘

┌─ 底层项区（bottom） ──────────────────────────────────┐
│  [3.65cm] [8.37cm] [13.10cm] [17.82cm]                  │
│  4 个 item box 横排                                      │
└────────────────────────────────────────────────────────┘

┌─ 右侧栏（right sidebar）─────────────────────────────┐

└────────────────────────────────────────────────────────┘

┌─ 左侧标签列（left vertical）──────────────────────────┐

│  4 个纵向文字标签（标题内容 / 标题 / 四字示例 / 提示）   │
└────────────────────────────────────────────────────────┘
```

### Visual Style
- 分类头: 深蓝 #00479D 底 + 白字，圆角顶
- 子项: 白底细线，圆角
- 容器盒: 浅灰 #F2F2F2 底，圆角
- 连接元素: 虚线或箭头

### 变体建议（非强制 — 模板只有 1 套标准，按场景选用）

| 变体 | 适用场景 | 与标准差异 |
|------|----------|------------|
| 简化版（4 层） | 简单系统/概念图 | 去掉底层项区；保留 顶层 3 + 中层 4 + 右侧栏 |
| 扩展版（6 层） | 复杂企业架构 | 顶层增至 4 大类；中层 5 类别；底层 6 项 |

### 3 列内容模板

**左列 (2.47-9.93cm)**
- 「点标题：」+ 「单击此处输入您的内容。」 重复 4-5 次
- 文字居左，竖排

**中列 (11.46-19.98cm)**
- 圆角矩形「点标题」+ 正文段
- 每条目: 标题块 3.0×0.72cm + 段落 7.64×2.35cm
- 共 3 条目

**右列 (21.43-31.4cm)**
- 「点标题：单击此处输入您的正文。…」
- 段落装在大矩形 (9.0×1.62 / 9.0×3.32cm) 内
- 共 4-5 条目

### 视觉
- 列头: 色底白字，圆角顶
- 列身: 与列头同色调的极淡底色
- 底部胶囊: 圆角矩形 + 细边线
- 整体白底

## 16. Numbering, Variants & Image Rules

### 16.1 Numbering Hierarchy（设计规范 1.7）

| 级别 | 格式 | 示例 |
|------|------|------|
| 目录 | `01、02、03 …` | 01/ 基础样式模板 |
| 幻灯片标题 | `{章}.{节}` | 1.1、1.2、1.3 |

### 16.2 Animation Guidelines — 设计规范 2.3
- 默认不添加动画
- 若使用: 简约为主
- **4-7 个动画/整篇**（不是每张）
- 速度与演讲匹配
- 同类页面保持动画效果一致

### 16.3 Image Guidelines — 设计规范 2.5

| 维度 | 规则 |
|------|------|
| 质量 | 高清；不拉伸/不压缩；色彩鲜明 |
| 单图 | 定界框内**居中对齐** |
| 多图 | **错位排版**（0.5cm 步进），可加点击动画 |
| 版权 | 公司授权范围内 |

### 16.4 Watermark — 设计规范 2.6
- 白色版用浅灰水印
- 根据背景匹配对应水印
- 位置低调（中央或角落）
- 不喧宾夺主

- 模板中至少 3 张：slide 10、slide 15、slide 19
- 章节页**不放标题栏**，仅靠装饰方块识别
