  用途: 查询 4 项评估质量指标 (Indicator A01-A04)
  输入:
    SttDate - 出院开始日期 (YYYY-MM-DD)
    EndDate - 出院结束日期 (YYYY-MM-DD)
    LocID   - 科室ID列表 (逗号分隔, 空=全部)
  输出 JSON rows (4 条):
    [
      {
        IndicatorCode: "A01",
        IndicatorName: "VTE 风险评估率",
        Category:      "评估质量指标",
        Numerator:     1200,

      },
      {
        IndicatorCode: "A02",
        IndicatorName: "VTE 中高风险比例",
        Category:      "评估质量指标",
        Numerator:     506,
        Denominator:   1200,
        Rate:          "42.1",
        Target:        "-",
        Note:          "任意一次评估为中危/高危 / 接受过VTE评估的患者"
      },
      {
        IndicatorCode: "A03",
        IndicatorName: "出血风险评估率",

      }
    ]

  指标计算逻辑 (基于 VTE质控指标汇总-备注.docx):

  ┌─ 适用人群过滤 (所有指标共用) ─────────────────────────────┐
  │ 入组: 年龄 ≥ 13 岁 的住院患者 (PAADM类型=I)              │
  │ 排除:                                                    │
  │   a. 住院时间 ≤ 24h (DisDate - AdmDate <= 1 且时间差≤24h)│
  │   b. 已接受抗凝治疗者:                                    │
  │      - 已确诊 VTE (ICD编码: I26/I80/I82)                 │
  │      - 房颤 (ICD: I48)                                   │
  │      - 急性心肌梗死 (ICD: I21)                            │
  │      - 缺血性脑卒中 (ICD: I63)                            │
  │      - CRRT/ECMO/血液透析 (医嘱项判断)                    │
  │      - 机械瓣膜植入 (ICD: Z95.2)                          │
  │ 数据源:                                                  │
  │   ^PAADM(admId)       → 就诊记录(类型/日期/科室)         │
  │   ^PAPER(patId,"ALL") → 患者年龄/性别                    │
  │   ^MRC("ID",icdId)    → ICD诊断编码                      │
  └──────────────────────────────────────────────────────────┘

  A01 - VTE风险评估率:
    分母 = 符合入组条件的出院患者总数
    分子 = 分母中, 在入院24h内 Caprini评估表 或 Padua评估表
           "评估时机"字段不为空的患者数
    关键: 出院患者可能多次入院，取统计时段内的出院记录
    备注: 手术患者用Caprini, 非手术患者用Padua, 肿瘤可联合Khorana

  A02 - VTE中高风险比例:
    分母 = A01的分子 (已评估患者数)
    分子 = 分母中, 任意一次Caprini/Padua评估结果为
           "中危" 或 "高危" 或 "极高危" 的患者数
    风险等级映射: 低危/中危/高危/极高危 ← 需确认存储字段名

  A03 - 出血风险评估率:
    分母 = A02的分子 (VTE中高危患者数)
    分子 = 分母中, 有出血风险评估记录的患者数
           (非手术患者: "知情同意书-出血因素" 不为空)
           (手术患者:   "外科住院患者出血风险评估量表" 不为空)

  A04 - 出血高风险比例:
    分母 = A03的分子 (接受出血评估的患者数)
    分子 = 分母中, 出血风险评估结果为 "高危" 或 "极高危" 的患者数

== 3. 预防质量指标: web.dhcvte.QryIndicators::QryPreventionIndicators ==
  用途: 查询 4 项预防质量指标 (Indicator P01-P04)
  输入: 同 QryAssessmentIndicators
  输出 JSON rows (4 条):
    [
      {
        IndicatorCode: "P01",
        IndicatorName: "药物预防实施率",
        Category:      "预防质量指标",
        Numerator:     223,
        Denominator:   372,
        Rate:          "59.9",
        Target:        "≥60%",
        Note:          "勾选药物预防 / VTE中高危∩出血低危"
      },
      {
        IndicatorCode: "P02",
        IndicatorName: "机械预防实施率",
        Category:      "预防质量指标",
        Numerator:     34,
        Denominator:   75,
        Rate:          "45.3",
        Target:        "≥50%",
        Note:          "勾选机械预防 / VTE中高危∩出血高危"
      },
      {
        IndicatorCode: "P03",
        IndicatorName: "联合预防实施率",
        Category:      "预防质量指标",
        Numerator:     89,
        Denominator:   297,
        Rate:          "30.0",
        Target:        "≥30%",
        Note:          "药物+机械都勾选 / VTE高危∩出血低危"
      },
      {
        IndicatorCode: "P04",
        IndicatorName: "VTE 规范预防率",
        Category:      "预防质量指标",
        Numerator:     120,
        Denominator:   218,
        Rate:          "55.0",
        Target:        "≥55%",
        Note:          "极高危且已实施预防 / VTE极高危患者"
      }
    ]

  指标计算逻辑:

  P01 - 药物预防实施率:
    分母 = VTE中高危 (A02分子) ∩ 出血低危 的患者
    分子 = 分母中, Caprini/Padua评估表 "药物预防" 勾选框已勾选的患者数
    字段参考: Caprini/Padua表中 → 药物预防: 勾选=1

  P02 - 机械预防实施率:
    分母 = VTE中高危 (A02分子) ∩ 出血高危/极高危 的患者
    分子 = 分母中, Caprini/Padua评估表 "机械预防" 勾选框已勾选的患者数
    意义: 出血高风险患者无法安全使用抗凝药物, 机械预防是核心手段
          (梯度压力弹力袜、间歇充气加压装置等)

  P03 - 联合预防实施率:
    分母 = VTE高危/极高危 ∩ 出血低危 的患者
    分子 = 分母中, "药物预防" AND "机械预防" 都勾选的患者数

  P04 - VTE规范预防率:
    分母 = VTE评估为 "极高危" 的患者
    分子 = 分母中, 已实施任意预防措施 (药物/机械任一勾选) 的患者数
    注意: 部分地区将此指标作为综合指标使用

== 4. 患者明细: web.dhcvte.QryPatientList::QryByIndicator ===========
  用途: 点击指标行后, 查询该指标对应的患者列表
  输入:
    SttDate       - 出院开始日期
    EndDate       - 出院结束日期
    LocID         - 科室ID列表 (逗号分隔)
    IndicatorCode - 指标代码 (A01/A02/A03/A04/P01/P02/P03/P04)
  输出 JSON rows (分页):
    [
      {
        RegNo:          "ZY0000001",
        PatName:        "张三",
        Sex:            "男",
        Age:            65,
        LocDesc:        "骨科",
        WardDesc:       "骨科一区",
        AdmDate:        "2026-05-03",
        DisDate:        "2026-05-15",
        VTERiskLevel:   "高危",
        BleedRiskLevel: "低危",
        DrugPrev:       "Y",
        MechPrev:       "N"
      }
    ]

  字段说明:
    RegNo          登记号      ^PAPER(patId,"PAT",1) REGNO
    PatName        患者姓名    ^PAPER(patId,"ALL") Name
    Sex            性别        ^PAPER(patId,"ALL") Sex
    Age            年龄        从出生日期计算
    LocDesc        科室名称    ^CTLOC(locId) 名称
    WardDesc       病区名称    ^PAADM(admId) 病区
    AdmDate        入院日期    ^PAADM(admId) AdmDate → $zd格式化
    DisDate        出院日期    ^PAADM(admId) DisDate → $zd格式化
    VTERiskLevel   VTE风险等级 Caprini/Padua评分 → 低危/中危/高危/极高危
    BleedRiskLevel 出血风险等级 出血评估量表 → 低危/中危/高危/极高危
    DrugPrev       药物预防    Caprini/Padua表中勾选 → Y/N
    MechPrev       机械预防    Caprini/Padua表中勾选 → Y/N

  各指标返回患者子集定义:
    A01: 分母人群中有Caprini/Padua评估记录的患者
    A02: A01中评估结果为中危/高危/极高危的患者
    A03: A02中有出血评估记录的患者
    A04: A03中出血评估为高危/极高危的患者
    P01: VTE中高危∩出血低危 中药物预防=Y的患者
    P02: VTE中高危∩出血高危 中机械预防=Y的患者
    P03: VTE高危∩出血低危 中药物=Y AND 机械=Y的患者
    P04: VTE极高危 中药物=Y OR 机械=Y的患者

== 数据存储参考 (来自现有HIS Global结构) ============================

function FormatDate(d) {
    var y = d.getFullYear();
    var m = ('0' + (d.getMonth() + 1)).slice(-2);
    var day = ('0' + d.getDate()).slice(-2);
    return y + '-' + m + '-' + day;
}

function ValidateDateRange() {
    if (me.SttDate > me.EndDate) {
        me.EndDate = me.SttDate;
        $('#EndDate').datebox('setValue', me.EndDate);
    }
}

function SetDatePreset(type) {
    me.activePreset = type;
    var now = new Date(); var stt;
    switch (type) {
        case 'today': stt = now; break;
        case 'week':  stt = new Date(now); stt.setDate(stt.getDate() - 7); break;
        case 'month': stt = new Date(now.getFullYear(), now.getMonth(), 1); break;
        case 'last':  stt = new Date(now.getFullYear(), now.getMonth() - 1, 1);
                      now = new Date(now.getFullYear(), now.getMonth(), 0); break;
    }
    me.SttDate = FormatDate(stt);
    me.EndDate = FormatDate(now);
    $('#SttDate').datebox('setValue', me.SttDate);
    $('#EndDate').datebox('setValue', me.EndDate);
    $('.dp-btn').removeClass('active');
    $('#dp_' + type).addClass('active');
}

function DoExport() {
    var assessRows = $('#dgAssessment').datagrid('getRows') || [];
    var prevRows  = $('#dgPrevention').datagrid('getRows') || [];
    var allRows = assessRows.concat(prevRows);
    if (allRows.length === 0) {
        $.messager.alert('提示', '请先查询数据后再导出', 'info');
        return;
    }
    var headers = ['指标类别','指标名称','分子','分母','比率(%)','目标值','备注'];
    var fields  = ['Category','IndicatorName','Numerator','Denominator','Rate','Target','Note'];
    var csv = '﻿' + headers.join(',') + '\n';
    for (var r = 0; r < allRows.length; r++) {
        var row = [];
        for (var f = 0; f < fields.length; f++) {
            var v = allRows[r][fields[f]];
            v = (v != null) ? String(v).replace(/"/g, '""') : '';
            if (v.indexOf(',') > -1 || v.indexOf('"') > -1 || v.indexOf('\n') > -1) v = '"' + v + '"';
            row.push(v);
        }
        csv += row.join(',') + '\n';
    }
    var blob = new Blob([csv], { type: 'text/csv;charset=utf-8' });
    var link = document.createElement('a');
    link.href = URL.createObjectURL(blob);
    link.download = 'VTE_Indicators_' + me.SttDate.replace(/-/g, '') + '_' + me.EndDate.replace(/-/g, '') + '.csv';
    link.click();
}

        + '&IndicatorCode=' + encodeURIComponent(me.patientParams.IndicatorCode)
        + '&page=1&rows=99999';
    $.ajax({

        success: function (data) {

            var allRows = data.rows || [];
            if (allRows.length === 0) {
                $.messager.alert('提示', '没有数据可以导出！');
                return;

            var headers = ['登记号','患者姓名','性别','年龄','科室','病区','入院日期','出院日期','诊断','VTE评分','VTE风险等级','出血风险等级','药物预防','机械预防'];
            var fields  = ['RegNo','PatName','Sex','Age','LocDesc','WardDesc','AdmDate','DisDate','Diag','VTEScore','VTERiskLevel','BleedRiskLevel','DrugPrev','MechPrev'];
            var csv = '﻿' + headers.join(',') + '\n';
            for (var r = 0; r < allRows.length; r++) {
                var row = [];
                for (var f = 0; f < fields.length; f++) {
                    var v = allRows[r][fields[f]];
                    v = (v != null) ? String(v).replace(/"/g, '""') : '';
                    if (v.indexOf(',') > -1 || v.indexOf('"') > -1 || v.indexOf('\n') > -1) v = '"' + v + '"';
                    row.push(v);
                }
                csv += row.join(',') + '\n';
            }
            var blob = new Blob([csv], { type: 'text/csv;charset=utf-8' });
            var link = document.createElement('a');

            link.download = 'VTE_Patients_' + me.SttDate.replace(/-/g, '') + '_' + me.EndDate.replace(/-/g, '') + '.csv';

        },
        error: function () {
            $.messager.progress('close');

        }
    });
}
