取数方式（两种任选其一）：
1. SQL 适用于 HIS 已有标准 SQL 表（如 CT_Loc、CT_Nation）。 在 SQL 语句 框填写完整的 SELECT 语句，结果集需包含三列： id（隐藏主键，可选）、code（对照代码）、desc（对照描述）。 可用 WHERE 过滤和 TOP n 限制；列名不固定，SQL 中按需要用 AS 代码、AS 描述 重命名即可。

2. 枚举 适用于标准表还没有或临时枚举的情况。 在 枚举项 框按行填写 代码=名称，例如 1=是 / 2=否；空行和 # 开头行会被忽略。

提示：新增或调整后务必先点【探测】看样本数据，确认"描述"列取值正确后再启用。
