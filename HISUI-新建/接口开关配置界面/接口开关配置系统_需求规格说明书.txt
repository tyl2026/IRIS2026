一、业务逻辑模型
================================================================

接口节点实际状态 = 该接口总开关 AND 该节点自身开关

┌──────────┬──────────┬──────────────┐
│ 接口总开关 │ 节点开关  │ 节点实际状态   │
├──────────┼──────────┼──────────────┤
│ 开       │ 开       │ 开           │
│ 开       │ 关       │ 关           │
│ 关       │ 开       │ 关           │
│ 关       │ 关       │ 关           │
└──────────┴──────────┴──────────────┘

每个接口独立一套开关体系，互不影响。

二、功能模块
================================================================

模块 1：接口开关配置界面（CSP 页面）
----------------------------------------------------------------

页面布局：所有接口纵向展开，无需Tab切换

┌────────────────────────────────────────────┐
│  接口开关配置                               │
├────────────────────────────────────────────┤
│  ▌ 挂号接口                        总开关  │
│  │   [ON]                            [ON]  │
│  │  ┌──────────┬──────────┬──────┐        │
│  │  │ 节点名称  │ 节点开关 │ 状态 │        │
│  │  ├──────────┼──────────┼──────┤        │
│  │  │ 挂号查询  │  [ON] ✓  │ 开   │        │
│  │  │ 创建挂号  │  [OFF]   │ 关   │        │
│  │  │ 取消挂号  │  [ON] ✓  │ 开   │        │
│  │  └──────────┴──────────┴──────┘        │
│  │  [+ 新增节点]                           │
├────────────────────────────────────────────┤
│  ▌ 处方接口                        总开关  │
│  │   [OFF]                           [OFF] │
│  │  ┌──────────┬──────────┬──────┐        │
│  │  │ 节点名称  │ 节点开关 │ 状态 │        │
│  │  ├──────────┼──────────┼──────┤        │
│  │  │ 处方查询  │  [ON]    │ 关*  │        │
│  │  │ 处方开具  │  [ON]    │ 关*  │        │
│  │  └──────────┴──────────┴──────┘        │
├────────────────────────────────────────────┤
│  [+ 新增接口]                              │
└────────────────────────────────────────────┘

交互细节：

1. 所有接口纵向排列，一屏显示，超过一屏时页面滚动
2. 每个接口区域包含：接口名称标题、总开关、节点表格
3. 节点表格列：节点名称、节点开关（switchbutton）、实际状态（计算列，灰色只读）
4. 接口总开关关闭 → 该接口的节点表格整区置灰，节点开关不可操作，实际状态列统一「关」
5. 接口总开关打开 → 节点表格恢复可操作，实际状态按 AND 逻辑计算显示
6. 底部「新增接口」按钮 → 弹出输入框填写接口编码和接口名称
7. 每个接口区域底部「新增节点」按钮 → 弹出输入框填写节点编码和节点名称
8. 支持删除接口（弹确认：将同时删除下属所有节点）
9. 支持删除单个节点（弹确认）
10. 接口名称旁有删除接口按钮（图标或文字）
11. 节点表格每行有删除节点按钮
12. 所有开关切换即时 AJAX 保存，顶部轻提示结果

模块 2：获取开关状态接口（CLS 方法）
----------------------------------------------------------------

调用方式：直接调用 CLS 方法
  Set json = ##class(web.YZSY.YZSYInterfaceSwitchManager).GetSwitchStatus("REG")

参数：
  interfaceCode：可选，不传则返回所有接口状态

返回格式（JSON）：
{
    "InterfaceCode": "REG",
    "InterfaceName": "挂号接口",
    "MasterSwitch": "ON",
    "Nodes": [
        {
            "Code": "REG_QUERY",
            "Name": "挂号查询",
            "Switch": "ON",
            "Status": "ON"
        },
        {
            "Code": "REG_CREATE",
            "Name": "创建挂号",
            "Switch": "OFF",
            "Status": "OFF"
        },
        {
            "Code": "REG_CANCEL",
            "Name": "取消挂号",
            "Switch": "ON",
            "Status": "ON"
        }
    ]
}

其中：
  Switch：节点开关本身的配置值（ON/OFF）
  Status：计算后的实际状态（MasterSwitch AND Switch）

不传 interfaceCode 时返回所有接口的数组：
[
    { "InterfaceCode": "REG", "InterfaceName": "挂号接口", ... },
    { "InterfaceCode": "RX",  "InterfaceName": "处方接口", ... }
]

三、数据存储设计
================================================================

全局变量前缀：^YZSYInterfaceSwitch

^YZSYInterfaceSwitch("InterfaceDef", interfaceCode) = "接口中文名"
^YZSYInterfaceSwitch("NodeDef", interfaceCode, nodeCode) = "节点中文名"
^YZSYInterfaceSwitch("Master", interfaceCode) = "ON" / "OFF"
^YZSYInterfaceSwitch("Node", interfaceCode, nodeCode) = "ON" / "OFF"

说明：
- 每个接口的总开关和节点开关独立存储，互不影响
- 接口定义和节点定义为元数据，删除接口时一并清理下属所有数据
- 新增接口时默认总开关 OFF，新增节点时默认节点开关 OFF

五、前端设计
================================================================

技术栈：HISUI 框架

页面模板标签：
  <EXTHEALTH:HEAD>
  <HISUI>

CSS 类名：hisui-* 系列
JS API：EasyUI 标准 API

配色方案：
  body 背景：  #cee4ff
  标签/标题色： #15428b
  面板/表格背景：#F9FBFF

组件选型：
  接口总开关：EasyUI switchbutton
  节点开关：datagrid 内嵌 switchbutton（formatter 渲染）
  接口列表：动态生成的 HTML 区域块（eachart 或纯JS循环构建）
  通信：$cm 调用后端 CLS 方法

核心 JS 逻辑：
1. 页面加载 → $cm 调 GetAllInterfaces() → 动态渲染所有接口区域
2. 总开关 onChange → $cm 调 SetMasterSwitch() → 刷新该接口节点表格状态/禁用态
3. 节点开关 onChange → $cm 调 SetNodeSwitch() → 更新该行状态列 + 轻提示
4. 新增接口 → $cm 调 AddInterface() → 在页面底部追加新接口区域
5. 新增节点 → $cm 调 AddNode() → 刷新对应接口的节点表格
6. 删除接口 → 确认 → $cm 调 DeleteInterface() → 移除该接口区域
7. 删除节点 → 确认 → $cm 调 DeleteNode() → 移除该行
