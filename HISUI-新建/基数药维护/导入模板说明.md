# 基数药维护 — 导入模板说明

## 一、功能说明

基数药维护页面新增三个功能：

| 功能 | 说明 |
|------|------|
| 翻页 | 表格启用服务端分页，默认每页 20 条，可切换 20/50/100/200 条/页 |
| 导出 | 按当前筛选条件（院区 + 类型）导出**全部**数据为 CSV（UTF-8 带 BOM，Excel 可直接打开），**含 药品代码/用法代码/科室代码 列** |
| 导入 | 选择 Excel（.xls/.xlsx）或 **CSV** 文件批量新增基数药记录 |

## 二、导出 → 修改 → 导入 闭环

导出的 CSV 文件列如下（**前 7 列与导入模板一致**，可直接作为导入文件使用）：

```
类型, 药品代码, 药品名称, 用法代码, 用法, 开单科室代码, 开单科室, 取药科室代码, 取药科室, 使用科室代码, 使用科室, 备注
```

典型用法（如批量把同一批科室配置复制给其他药品）：

1. 点击**导出**，得到当前筛选条件下的全部记录 CSV
2. 在 Excel 中打开，把需要变更记录的「药品代码」列改成新药品的代码（「药品名称」列仅供查看，导入时忽略）
3. 点击**导入**，选择修改后的 CSV 文件
4. 由于 类型+药品+开单科室+取药科室 组合变化，变更后的记录会作为**新增**记录写入；未修改的记录自动跳过

> 注意：Excel 中以数字保存的代码列会丢失前导 0，编辑代码列时请保持文本格式。

> **CSV 编码**：导出的 CSV 是 UTF-8 编码。若用 Excel 修改后**另存为 CSV**，中文版 Excel 默认存成 GBK 编码，导入时会自动按 GBK 再解析一次（一般无需处理）；若提示"列名不匹配"，请在 Excel 另存时选择 **"CSV UTF-8"** 格式（或文件类型选 CSV UTF-8）再导入。

## 二、导入模板列说明

模板文件见同目录 `导入模板.xlsx`，列定义如下（**首行必须是列名**，顺序可调整，列名不能改）：

| 列名 | 必填 | 说明 |
|------|------|------|
| 类型 | 是 | 门诊 / 住院（也支持 O / I） |
| 药品代码 | 是 | 医嘱项代码（ARCIM 代码），系统按代码精确匹配 |
| 用法代码 | 否 | 用法代码（PHCIN 代码，留空表示不维护用法；代码匹配不上时按名称兜底） |
| 开单科室代码 | 是 | 科室代码（CTLOC 代码），系统按代码精确匹配 |
| 取药科室代码 | 是 | 科室代码（CTLOC 代码），系统按代码精确匹配 |
| 使用科室代码 | 否 | 科室代码（CTLOC 代码），留空表示不维护使用科室 |
| 备注 | 否 | 备注文字 |

> 匹配方式为**全部按代码匹配**：药品按医嘱项代码、科室按科室代码。
> 代码列请使用**文本格式**填写，避免以数字存储导致前导 0 丢失。

## 三、导入规则

1. **必填校验**：类型、药品代码、开单科室代码、取药科室代码 缺失或匹配不到 → 该行计入失败
2. **院区校验**：科室已挂院区且与当前选择院区不一致 → 该行计入失败（未挂院区的科室不拦截）
3. **去重**：类型 + 药品 + 开单科室 + 取药科室 完全相同的记录**自动跳过**（重复行、文件内重复、与库内已有数据重复均跳过）
4. 导入结果提示：成功 N 条 / 跳过 M 条 / 失败 K 条，失败行会显示第几条及原因
