> 项目：门诊药房管理系统（HISUI-新建/基数药维护）
> 日期：2026-08-26
> 内容：翻页、导出、数据导入（Excel/CSV）三项功能开发 + 开发中问题修复记录

## 一、功能概述

| 功能 | 说明 |
|------|------|
| 翻页 | 列表启用服务端分页，默认每页 20 条，可切换 20/50/100/200 条/页 |
| 导出 | 按当前筛选条件（院区+类型）导出**全部**数据为 CSV（UTF-8 带 BOM），**含药品/科室代码列** |
| 导入 | 支持 Excel（.xls/.xlsx）和 **CSV** 文件批量新增，药品/科室按**代码匹配**，已存在记录自动跳过，完成后反馈成功/跳过/失败数量及原因 |
| 导出→导入闭环 | 导出的 CSV 可直接修改「药品代码」列后作为导入文件，实现批量复制同科室配置给其他药品 |
| 帮助说明 | 「帮助」悬浮说明更新，覆盖翻页/新增/删除/导出/导入全部操作 |

## 二、界面变更

### 1. 工具栏（`pha.op.v4.basemed.csp`）

- 新增按钮：**导出**（icon-w-export）、**导入**（icon-w-import）
- 新增文件选择框：`hisui-filebox`（支持 `.xls / .xlsx / .csv`）
- 引入 Excel 解析脚本：`../scripts/xlsx.full.min.js`

### 2. 列表（`basemed.js`）

- 分页配置：`pagination: true, pageNumber: 1, pageSize: 20, pageList: [20,50,100,200]`
- **初始化方式改为原生 datagrid**：`$('#gridBaseMed').datagrid(dataGridOption)`
  - 原因：原 `PHA.Grid(...)` 封装不透传分页选项，分页器不显示（同项目「标识码独立维护」页面有相同处理先例）
- 移除 queryParams 中写死的 `rows: 999`，分页参数由分页器自动下发

### 3. 导出（`ExportBaseMed`）

- 重新查询全量数据（`ResultSetType: 'array'` + `rows: 999999`），不受分页限制
- 输出列（12 列，**前 7 列与导入模板一致**）：

  ```
  类型, 药品代码, 药品名称, 用法代码, 用法, 开单科室代码, 开单科室,
  取药科室代码, 取药科室, 使用科室代码, 使用科室, 备注
  ```

- CSV 首字符 BOM（`\ufeff`），Excel 直接打开不乱码
- IE11 兼容：`navigator.msSaveBlob` 兜底

### 4. 导入（`ImportBaseMed` / `ImportRows`）

- 按文件扩展名自动识别：`.csv` → CSV 解析器；其余 → SheetJS 解析 Excel 第一个工作表
- **列名规范化**：自动去首尾空格（兼容 Excel 列名带空格）
- **跳过全空行**（如 CSV 尾部空行）
- 解析失败诊断：提示实际读到的列名 + 编码建议（"另存为 CSV UTF-8"）

### 5. 帮助说明（`HelpInfo`）

- 更新为「操作说明」：翻页（每页条数切换）、新增（双击行编辑、必填项）、删除、导出（含代码列）、导入（代码匹配、去重、闭环用法）

## 三、后端变更

### 1. `PHA.OP.CfBase.Query.cls`（需重新编译）

`QueryLocBaseMed` 查询新增 5 个**代码输出字段**（导出依赖）：

| 字段 | 来源 |
|------|------|
| `arcItmCode` 药品代码 | `^ARCIM(sub,ver,1)` 第 1 段 |
| `instCode` 用法代码 | `^PHCIN(instDr)` 第 1 段 |
| `docLocCode` 开单科室代码 | `^CTLOC(docLocDr)` 第 1 段 |
| `useLocCode` 取药科室代码 | `^CTLOC(useLocDr)` 第 1 段 |
| `exeLocCode` 使用科室代码 | `^CTLOC(+exeLocDr)` 第 1 段 |

### 2. `PHA.OP.CfBase.Import.cls`（新增类，需编译）

`ImportBaseMed(pJsonStr)` 导入方法：

- **入参**：`{"hospId":"院区ID","rows":[{baseMedType, arcItmCode, instCode, docLocCode, useLocCode, exeLocCode, remarks}]}`
- **字典映射**（代码 → rowid）：
  - 药品：`^ARCIM(0,"Code")` 索引，索引为空时全表扫描兜底（跳过 `0` 索引子树）
  - 科室：`^CTLOC(0,"Code")` 索引 + 兜底扫描
  - 用法：`^PHCIN` 代码映射，代码匹配不上按名称兜底
- **逐行校验**：
  - 类型归一化：门诊→O、住院→I（也接受 O/I）
  - 必填：类型、药品代码、开单科室代码、取药科室代码
  - 院区校验：科室已挂院区且与当前院区不一致时拦截（未挂院区的科室不拦截）
- **去重**：`类型+药品+开单科室+取药科室` 完全相同 → 跳过（含文件内重复）
- **并发安全**：`l +^DHCPHBMED:10` 锁 + `ts/tc/tro` 事务
- **返回**：`{"success","ok","skip","err","msg","errRows":[{"row","msg"}]}`

数据写入结构：`^DHCPHBMED(id) = 药品^用法^开单科室^取药科室^备注^类型^使用科室`

## 四、开发中解决的问题（重要）

| 问题 | 根因 | 修复 |
|------|------|------|
| 编译错误 #1043 `QUIT argument not allowed` | `catch` 块内不允许带参数的 `quit` | 改用 `errFlag/errMsg` 变量，`quit` 移到 try/catch 之外 |
| 运行错误 `*%Get`（第 7 行） | `$g()` 包住了方法调用 `pJson.%Get(...)`，`$g` 只接受变量/全局引用 | 去掉 8 处 `$g(方法调用)` 包装，保留 `$g(全局/数组引用)` |
| 运行错误 `^ARCIM(0,"ARCIC_DR",1)` `<UNDEFINED>` | 兜底扫描把 `0` 下标（索引子树）当药品数据；`$d()` 对"只有子节点无值"的父节点返回 10，守卫放行后裸读无值节点崩溃 | 读取全部 `$g()` 保护 + 扫描跳过 `+id=0` 索引子树 |
| 导入提示"没有有效的数据行" | ① Excel 另存 CSV 变成 GBK 编码，按 UTF-8 读中文列名乱码；② 兜底路径把二维数组直接当对象数组，列名变成数字 0-7 | ① CSV 多策略解析（UTF-8 → XLSX codepage 936 → TextDecoder gbk）；② 新增 `tableToObjects` 二维数组转对象数组（列名去 BOM/去空格） |
| 分页器不显示 | `PHA.Grid()` 封装不透传分页选项 | 改用原生 `$('#gridBaseMed').datagrid(dataGridOption)` |

## 六、部署步骤

1. **编译后端类**（终端/Studio）：

   ```objectscript
   d $system.OBJ.Compile("PHA.OP.CfBase.Query","ck")
   d $system.OBJ.Compile("PHA.OP.CfBase.Import","ck")
   ```

   > `Query` 类不编译则导出 CSV 的代码列为空，再导入会报「药品代码未匹配」。

2. **部署前端**：覆盖 `csp/pha.op.v4.basemed.csp`、`scripts/pha/op/v4/basemed.js`
3. **依赖**：服务器需存在 `../scripts/xlsx.full.min.js`（同院区「团体导入」页面已在使用，通常已具备）
4. **验证**：翻页 → 导出 → 修改代码 → 导入，走一遍闭环

## 七、使用要点与注意事项

1. **导入匹配方式**：全部按**代码**匹配（药品=医嘱项代码 ARCIM、科室=CTLOC 代码、用法=PHCIN 代码），模板列名不能改、顺序可调
2. **代码列保持文本格式**：Excel 中以数字保存会丢前导 0
3. **CSV 编码**：导出的 CSV 是 UTF-8；用 Excel 另存为 CSV 会变 GBK，系统会自动尝试 GBK 再解析；仍失败时按提示另存为「CSV UTF-8」
4. **去重**：`类型+药品+开单科室+取药科室` 相同即跳过，所以"导出→改药品代码→导入"可批量生成新药品的基数药配置
5. **翻页与编辑**：编辑中的行切换页面会被丢弃，先点「保存」再翻页
