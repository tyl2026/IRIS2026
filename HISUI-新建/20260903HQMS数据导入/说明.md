# HQMS 病案首页数据导入与查询 —— 部署/使用说明

> 代码目录：`HISUI-新建/20260903HQMS数据导入/01代码实现/`
> 目标表：`User.YZSYHQMSData`（按国家病案首页采集接口标准 2020-06-29 字段全集建表，811 文档列 + 5 语义索引列 + 6 控制列）

## 一、交付文件

| 文件 | 用途 |
|---|---|
| `User.YZSYHQMSData.cls` | HQMS 数据表（811 标准码列 + IDCardNo/RYRQ/CYRQ/MainDiag/MainOper 语义列 + BatchNo/SrcRowNo/SrcFileName/ImpUser/ImpDate/ImpTime 控制列；5 个语义索引 + 批次行唯一索引） |
| `User.YZSYHQMSDataDic.cls` | 值域字典表（接口文档 RC001…RC039：427 值域项 + 276 条 字段→值域 绑定） |
| `User.DHCMRInfoHQMSLog(.Item)` | 导入日志主表/明细表 |
| `web.YZSY.HQMSFieldMeta.cls` | HQMS 字段元数据（码/中文名/类型/分组 822 项）与五语义列默认来源 |
| `web.YZSY.HQMSDicInit.cls` | 字典种子与初始化 `EnsureSeed()`（值域项+字段绑定） |
| `web.YZSY.DHCMRInfoHQMSDict.cls` | DHCMRINFO 属性字典（MR 对照参考）与 UTF-8 探测 |
| `web.YZSY.DHCMRInfoHQMSImport.cls` | 导入后端：解析/指纹去重/审核/校验/导入/日志/删除 |
| `web.YZSY.DHCMRHQMSQuery.cls` | 自定义查询后端（动态选列/条件/分页；导出由前端 Blob 生成，无服务端文件） |
| `yzsyhqmsimport.csp/.js` | 导入界面（批次与上传/数据审核与导入/导入日志） |
| `dhcmrhqmsquery.csp/.js` | 自定义查询界面 |

## 二、部署步骤

1. **编译顺序**（类间有互相调用，按序一次编译全部即可）：
   `User.*` 4 个表类 → `web.YZSY.HQMSFieldMeta` → `web.YZSY.HQMSDicInit` → `web.YZSY.DHCMRInfoHQMSDict` → `web.YZSY.DHCMRInfoHQMSImport` → `web.YZSY.DHCMRHQMSQuery`。
2. **初始化字典**（首次必做，终端执行一次）：
   ```objectscript
   w ##class(web.YZSY.HQMSDicInit).EnsureSeed()
   ```
   预期返回 `{"success":1,"items":427,"binds":276}`。表已有数据时自动跳过；如需重建先清空表再执行：`&sql(delete from SQLUser.YZSYHQMSDataDic)` 后重新运行 `EnsureSeed()`。
3. **自检命令**：
   ```objectscript
   w $l(##class(web.YZSY.HQMSFieldMeta).GetMeta())          // 元数据长度>0
   w ##class(web.YZSY.DHCMRInfoHQMSImport).EnsureDic()       // {"success":1}
   w ##class(web.YZSY.DHCMRHQMSQuery).GetFieldMeta()         // JSON
   ```
4. **压测真实样例**（用项目根目录 `hqmsts_2026-09-02-00001.csv`（用作样例时请先改名为年月格式，如 `202601.csv`））：在导入页【批次与上传】选择文件点「上传并解析」即可（前端本地解析后提交后端，自动指纹去重）。
5. **页面地址**（与 门诊信息首页生成下载 相同的 CSP 部署目录）：
   - 导入：`yzsyhqmsimport.csp`
   - 查询：`dhcmrhqmsquery.csp`
   - JS 部署：两个 `.js` 复制到 csp 同级的 `../scripts/` 目录（保持与页面 src 相对路径一致）。

## 三、主要规则

- **文件命名（强制）**：文件名须为 6 位年月，如 `202601` 或 `202601.csv`；上传前/服务端双重校验，不符合命名要求的文件不能导入。
- **编码**：CSV 逗号分隔，首行字段码表头；自动识别 GBK/GB18030 与 UTF-8（文件头 128KB+尾 8KB 采样）；支持字段双引号包裹（`""`转义），不支持引号内跨行换行。
- **表头对齐**：文件码与表列默认“码名一致”入库（A11→A11…）；非标准码列在“字段核对”中可改指其他列（下拉限合法列），不改则不落库并提示。
- **五语义索引列**（导入时自动提取，可在字段核对改来源）：身份证号←A20、入院日期←B12、出院日期←B15、主要诊断(出院主要诊断名称)←C04N、主要手术(主要手术操作名称)←C14x01N。
- **校验（导入前逐行，不通过则拦截并记日志）**：
  - 值域字典（User.YZSYHQMSDataDic）；科室/麻醉方式/监护室/省份类本地码值域跳过（NOCHECKDIC）。
  - 必填且禁"-"核心字段：A11 A12C A13 A48 A49 A20 B12 B15 C01C C02N C03C C04N。
  - 格式：数字列须数值、日期列须合法、身份证 18 位含校验位/15 位数字。
  - 跨字段（文档 TABLE30 核心）：入院≤出院；主要手术日期在 [入院-1天, 出院]；诊断 ICD 码首字母须 A~U 或 Z。
- **防重复导入（纯新增）**：上传文件自动计算指纹，若已存在同文件批次（含已导入）直接拒绝；同批次不可二次导入。**如需重新导入：先对已导入批次执行【删除导入数据】**（删除 YZSYHQMSData 对应行+日志+归档），再重新上传。
- **原始文件追溯**：上传原文件自动归档到 `/tmp/hqms/archive/批次号_文件名`，删除批次/删除导入数据时一并清理。
- **写入**：每行新增一条；含 5 语义列与批次控制列；BatchNo+SrcRowNo 唯一索引兜底防重。

## 四、已知限制（如需再优化请提出）

1. 前端解析通道文件 ≤10MB（超过提示按年月拆分）；行内容 >28,000 字符的行拒绝入库（IRIS 单节点行宽防护，需用真实满行数据压测确认未触及节点上限）。
2. 超大文件仍同步解析（占请求通道），未做 JOB 异步+进度（可作为后续项）。
3. 字段中文名/值域字典以代码内嵌+播种维护；更新需改代码重编译（未做维护界面）。
4. 查询导出在前端本地分批生成并下载（Blob），无服务器端导出文件残留。
