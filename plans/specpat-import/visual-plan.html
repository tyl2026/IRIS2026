模板为 .xlsx 格式，首行为列名。用户用 Excel/WPS 填写，每行一条患者记录。

解析架构：前端 SheetJS + 后端数据接收
浏览器端
1. FileReader 读取 .xlsx
2. SheetJS (xlsx.js) 解析为数组
3. 转为 TSV 字符串
4. $.cm() 加密发送

服务端
1. ImportPatList 接收 TSV
2. $p 逐列解析
3. 代码→RowId 转换
4. InsertPatList 入库
数据格式：SheetJS 将 Excel 转为 TSV（Tab 分隔），首行表头跳过，后续行用 Tab 分隔列值。这样避免了 CSV 逗号与内容冲突的问题。

后端：ImportPatList 方法

新增 web.DHCSpecPat.ImportPatList(TSVContent, UserID, LocID)，接收前端 SheetJS 转换后的 TSV 字符串。

/// 批量导入特殊患者（前端已用 SheetJS 解析 .xlsx → TSV） ClassMethod ImportPatList(tsvContent As %String, UserID As %String, LocID As %String = "") As %String { s result = {} s result.total = 0, result.success = 0, result.skip = 0 s result.errors = [] s rows = $lfs(tsvContent, $c(10)) for i = 2:1:$ll(rows) { s line = $lg(rows, i) continue:(line = "") s name = $p(line, $c(9), 1) s credNo = $p(line, $c(9), 2) s typeCode = $p(line, $c(9), 3) s note = $p(line, $c(9), 4) s stDate = $p(line, $c(9), 5) s endDate = $p(line, $c(9), 6) s locCode = $p(line, $c(9), 7) #; 校验必填 if (name = "") || (credNo = "") || (typeCode = "") { d result.errors.%Push({"row":(i),"reason":"必填字段缺失"}) s result.skip = result.skip + 1 continue } #; 患者类型代码 → RowId s typeDr = $o(^DHCPatType(0,"Code",typeCode,"")) if (typeDr = "") { d result.errors.%Push({"row":(i),"reason":"类型代码无效: "_typeCode}) s result.skip = result.skip + 1 continue } #; 复用现有 InsertPatList 入库 s rtn = ..InsertPatList(name,credNo,note,typeDr,stDate,endDate,UserID,"",locCode) if (rtn = 0) { s result.success = result.success + 1 } else { d result.errors.%Push({"row":(i),"reason":(rtn)}) s result.skip = result.skip + 1 } } q result.%ToJSON() }
变更点：分隔符从逗号改为 Tab ($c(9))，避免 Excel 单元格内容含逗号导致的解析错误。首行表头跳过（i=2 起始）。

// IE11 兼容：FileReader + SheetJS function ImportPatListClick() { var input = document.createElement('input'); input.type = 'file'; input.accept = '.xlsx,.xls'; input.onchange = function(e) { var file = e.target.files[0]; if (!file) return; var reader = new FileReader(); reader.onload = function(evt) { // 非 Promise，IE11 兼容 var data = new Uint8Array(evt.target.result); var wb = XLSX.read(data, {type: 'array'}); var sheet = wb.Sheets[wb.SheetNames[0]]; // 转为 TSV 字符串（Tab 分隔） var tsv = XLSX.utils.sheet_to_csv(sheet, { FS: '\t', // 字段分隔符: Tab RS: '\n', // 行分隔符: 换行 strip: true // 去除首尾空格 }); // 预览前 3 行 → 确认 → $.cm() 加密发送 ShowImportPreview(tsv); }; reader.readAsArrayBuffer(file); }; input.click(); }
