### 后端变更

#### ImportPatList 方法

新增 `web.DHCSpecPat.ImportPatList(CSVContent, UserID, LocID)` 方法：

1. 解析 CSV 内容（逗号分隔，首行为列头，跳过）
2. 逐行校验必填字段（姓名、身份证号、患者类型）
3. 患者类型代码 → RowId 转换（查 `^DHCPatType`）
4. 科室代码 → RowId 转换（查 `^CTLOC`）
5. 调用现有 `InsertPatList` 逐行插入
6. 返回 JSON 结果：`{ total, success, skip, errors: [{row, reason}] }`

]]></RichText>

<Callout id="reuse-note" tone="info">

ImportPatList 复用 InsertPatList 的身份证号去重 + 日期校验逻辑，不重复实现。

</Callout>

<AnnotatedCode id="import-method" filename="web.DHCSpecPat.cls" language="objectscript" code={'ClassMethod ImportPatList(csvContent As %String, UserID As %String, LocID As %String = "") As %String
{
    s result = {}
    s result.total = 0, result.success = 0
    s result.skip = 0, result.errors = []

    s rows = $lfs(csvContent, $c(10))
    for i = 2:1:$ll(rows) {
        s line = $lg(rows, i)
        continue:(line = "")
        s result.total = result.total + 1

        s name = $p(line, ",", 1)
        s credNo = $p(line, ",", 2)
        s typeCode = $p(line, ",", 3)
        s note = $p(line, ",", 4)
        s stDate = $p(line, ",", 5)
        s endDate = $p(line, ",", 6)
        s locCode = $p(line, ",", 7)

        // 校验必填
        if (name = "") || (credNo = "") || (typeCode = "") {
            d result.errors.%Push({ "row": (i), "reason": "必填字段缺失" })
            s result.skip = result.skip + 1
            continue
        }

        // 患者类型代码→RowId
        s typeDr = $o(^DHCPatType(0, "Code", typeCode, ""))
        if (typeDr = "") {
            d result.errors.%Push({ "row": (i), "reason": "患者类型代码无效: "_typeCode })
            s result.skip = result.skip + 1
            continue
        }

        // 科室代码→RowId
        s locDr = ""
        if (locCode '= "") {
            s locDr = $o(^CTLOC(0, "Code", locCode, ""))
        }

        // 调用现有 InsertPatList
        s rtn = ..InsertPatList(name, credNo, note, typeDr, stDate, endDate, UserID, "", locDr)
        if (rtn = 0) {
            s result.success = result.success + 1
        } else {
            d result.errors.%Push({ "row": (i), "reason": (rtn) })
            s result.skip = result.skip + 1
        }
    }
    q result.%ToJSON()
}'} annotations={[
  { lines: "3-4", label: "返回结构", note: "JSON 格式，方便前端展示导入结果" },
  { lines: "7", label: "跳过表头", note: "i=2 起始，首行为列名" },
  { lines: "21-23", label: "类型代码转换", note: "通过 Code 索引查 RowId" },
  { lines: "34-38", label: "复用 InsertPatList", note: "已含身份证去重+日期校验" },
]} />
